# M7b Multipart Uploads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the second part of stage M7 in `typed_graphql_server`: file uploads by the GraphQL multipart request specification (R5.6). A schema declares the `Upload` scalar with `Uploads.codec`, the HTTP handler gets the same `Uploads` value through `HttpOptions.uploads`, and a `multipart/form-data` request is read part by part: `operations`, `map`, then each file streamed into an `UploadStorage` within `UploadLimits`. A resolver reads an `Upload`; the files are released after the response, whatever happened. It adds `GQL440`-`GQL442` to the core catalog, the CSRF pre-check for multipart bodies (deviation 8), the hostile-input tests and the Uploads guide.

**Architecture:** Everything lives in the server's new `lib/src/upload/` (dartdoc category `upload`, guide `doc/uploads.md`). The scalar codec has no request context, so the reader replaces each `null` the map names with an unguessable `upload:<32 hex digits>` token registered in the `Uploads` registry, and the codec looks the token up. `UploadMapParser` (with `MapPath`) validates the `map` field against the `operations`; `MultipartReader` drives `package:mime`'s `MimeMultipartTransformer` over a `WatchedBody` (a byte limit for the whole body, the body timeout, and the failures `package:mime` does not report into its stream) and `MultipartRun` reads the parts in order; `StoredUploads` releases what was stored. `GraphQLHttpHandler` sends `multipart/form-data` to the reader when uploads are on, after the CSRF check, and releases the uploads in a `finally`.

**Tech Stack:** Dart 3.13 (formatted with the 3.47.6 Flutter SDK's Dart 3.13.5), `package:test`, `package:meta`; `package:mime` (`^2.0.0`, already in the workspace lock as a transitive dependency) joins the server's dependencies and its allowed imports in Task 4.

**Spec:** `docs/superpowers/specs/2026-10-16-m7-transports-design.md` (sections 4, 8, 13, 14, 15 deviation 8, and 17), `docs/requirements.md` (R0.3, R5.6), the specification `reference/graphql-multipart-request-spec/readme.md`.

## Review Focus

1. Every refusal of spec section 8 has its status and code, is a transport refusal (`application/json`), and leaves nothing stored: on any refusal the stored uploads are released and their tokens removed; after a response they are released in a `finally`.
2. The limits are counted on the bytes that arrive: the whole body against `maxRequestBytes`, each JSON field against `maxFieldBytes`, each file against `maxFileBytes`, map keys and paths against `maxFiles`; `bodyTimeout` covers the whole body.
3. `package:mime` failures that do not reach its stream (a truncated body, a stream error inside a part, a parser exception thrown in the caller's zone) become refusals through `WatchedBody` and the guarded zone; only `Exception`s become refusals, an `Error` still propagates.
4. Tokens are 128 bits from `Random.secure`; the codec decodes only a registered token; nothing in a response or a message names a token or echoes request content.
5. The CSRF check runs before the body is read, so a forged multipart request never reaches the storage (deviation 8).

```dart
import 'dart:async';
import 'dart:convert';

import 'package:test/test.dart';
import 'package:typed_graphql_server/typed_graphql_server.dart';

void main() {
  const storage = MemoryUploadStorage();

  Future<Upload> storeChunks(List<List<int>> chunks) => storage.store(
    'notes.txt',
    'text/plain',
    Stream.fromIterable(chunks),
  );

  group('MemoryUploadStorage', () {
    test('keeps the file name and the media type', () async {
      final upload = await storeChunks([utf8.encode('hi')]);
      expect(upload.filename, 'notes.txt');
      expect(upload.mediaType, 'text/plain');
    });

    test('joins the chunks and reports the length', () async {
      final upload = await storeChunks([utf8.encode('he'), utf8.encode('llo')]);
      expect(upload.length, 5);
      expect(
        utf8.decode(
          (await upload.openRead().toList()).expand((c) => c).toList(),
        ),
        'hello',
      );
    });

    test('every openRead starts at the first byte', () async {
      final upload = await storeChunks([utf8.encode('abc')]);
      final first = await upload.openRead().expand((chunk) => chunk).toList();
      final second = await upload.openRead().expand((chunk) => chunk).toList();
      expect(second, first);
    });

    test('an empty file has length zero', () async {
      expect((await storeChunks([])).length, 0);
    });

    test('lets the error of the content through', () async {
      final failing = Stream<List<int>>.multi((controller) {
        controller
          ..add([1])
          ..addError(StateError('over the limit'))
          ..close();
      });
      await expectLater(
        storage.store('a', 'b', failing),
        throwsA(isA<StateError>()),
      );
    });

    test('release of an upload does nothing and does not throw', () async {
      final upload = await storeChunks([utf8.encode('x')]);
      await storage.release(upload);
      expect(upload.length, 1);
    });
  });
}
```

````markdown
# Uploads

A GraphQL multipart request carries files next to the operation (R5.6). This
guide describes the pieces a schema needs; the handler that reads multipart
requests comes with the HTTP transport.

## The pieces

- `Upload` is what a resolver reads: `filename`, `mediaType`, `length` and
  `openRead()`.
- `UploadStorage` is where a file waits until the response is built:
  `store` takes the file's bytes and returns an `Upload`, `release` frees it.
  `MemoryUploadStorage` keeps files in memory.
- `UploadLimits` bounds a request: `maxFiles`, `maxFileBytes`,
  `maxRequestBytes` and `maxFieldBytes`.
- `Uploads` holds a storage and the limits, and gives the schema its scalar.

## The scalar

One `Uploads` value is shared by the schema and the handler. The schema
declares the scalar with its codec:

```text
final uploads = Uploads();
final upload = b.scalar<Upload>(Uploads.scalarName, uploads.codec);
```

The scalar is input only: encoding an `Upload` is an `ArgumentError`. A
variable of type `Upload` reaches the resolver as the `Upload` the request
carried; any other value is a coercion error, "Upload value is not a file of
this request."

A storage keeps a file's bytes and hands back an `Upload`. This program stores
a file by hand, as the multipart reader does for each part:

```dart
import 'dart:convert';

import 'package:typed_graphql_server/typed_graphql_server.dart';

Future<void> main() async {
  const storage = MemoryUploadStorage();
  final upload = await storage.store(
    'notes.txt',
    'text/plain',
    Stream.value(utf8.encode('hello')),
  );
  print('${upload.filename} ${upload.mediaType} ${upload.length}');
  print(utf8.decode(await upload.openRead().expand((chunk) => chunk).toList()));
  await storage.release(upload);
}
```

It prints:

```text
notes.txt text/plain 5
hello
```

## Reading a file

An `Upload` is valid only during the request. The storage may delete the file
once the response is built, so read it in the resolver, before it returns,
and keep neither the `Upload` nor its stream.

## Writing a storage

`store` receives the content of one file as a stream. When that stream fails,
which is how a file over `maxFileBytes` is reported, drop what was written
and let the error through. `release` is called once per stored upload, after
the response is built, and must not throw for an upload it does not know.
````

```dart
/// An [UploadStorage] that keeps every file in memory.
///
/// It suits small files, and it is bounded by `UploadLimits.maxFileBytes` and
/// `UploadLimits.maxRequestBytes` per request. There is nothing to free, so
/// [release] does nothing: the bytes go with the [Upload].
///
/// {@category upload}
final class MemoryUploadStorage implements UploadStorage {
  /// Creates the storage.
  const MemoryUploadStorage();

  @override
  Future<Upload> store(
    String filename,
    String mediaType,
    Stream<List<int>> content,
  ) async {
    final bytes = BytesBuilder(copy: false);
    await for (final chunk in content) {
      bytes.add(chunk);
    }
    return MemoryUpload(filename, mediaType, bytes.takeBytes());
  }

  @override
  Future<void> release(Upload upload) async {}
}
```

```dart
import 'dart:math';

import 'package:meta/meta.dart';

import 'upload.dart';

/// The uploads of the requests being served, by the token that stands for
/// each in the request's variables.
///
/// The scalar codec has no request context, so a token is the only way a
/// value reaches the right file. A token is 128 random bits: a client cannot
/// guess another request's.
@internal
final class UploadRegistry {
  /// Creates an empty registry.
  UploadRegistry() : _random = Random.secure();

  final Random _random;
  final Map<String, Upload> _uploads = {};

  /// Registers [upload] and returns its new token.
  String register(Upload upload) {
    var token = _newToken();
    while (_uploads.containsKey(token)) {
      token = _newToken();
    }
    _uploads[token] = upload;
    return token;
  }

  /// The upload registered under [token], or null.
  Upload? lookup(String token) => _uploads[token];

  /// Forgets the uploads registered under [tokens].
  void remove(Iterable<String> tokens) {
    for (final token in tokens) {
      _uploads.remove(token);
    }
  }

  /// The number of uploads registered.
  int get length => _uploads.length;

  String _newToken() {
    final digits = StringBuffer('upload:');
    for (var index = 0; index < 16; index++) {
      digits.write(_random.nextInt(256).toRadixString(16).padLeft(2, '0'));
    }
    return digits.toString();
  }
}
```

```dart
import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

/// A place inside an `operations` value, written as the multipart request
/// specification writes it: segments joined by `.`.
///
/// A path names a place in the variables only: `variables.a.0` in a request,
/// `2.variables.a.0` in a batch. A segment is an object key or, for an array,
/// a decimal index with no sign and no leading zero.
@internal
final class MapPath {
  /// Creates the path of [text].
  MapPath(String text) : segments = text.split('.');

  static final RegExp _index = RegExp(r'^(0|[1-9][0-9]*)$');

  /// The keys and indices to follow from the root.
  final List<String> segments;

  /// The path as it was written, which is how two paths name one place.
  String get place => segments.join('.');

  /// Whether the path leads to an existing `null` inside the variables of
  /// [operations].
  bool isNullIn(JsonValue operations) {
    if (!_startsInVariables(operations)) return false;
    var node = operations;
    for (final segment in segments) {
      final child = _child(node, segment);
      if (child == null) return false;
      node = child;
    }
    return node is JsonNull;
  }

  /// A copy of [operations] with [replacement] at this path; the other values
  /// are shared with [operations]. The path must pass [isNullIn].
  ///
  /// It recurses once per segment, and a path that passed [isNullIn] is no
  /// longer than the nesting of the JSON it names.
  JsonValue replace(JsonValue operations, JsonValue replacement) =>
      _replaceAt(operations, 0, replacement);

  JsonValue _replaceAt(JsonValue node, int depth, JsonValue replacement) {
    if (depth == segments.length) return replacement;
    final segment = segments[depth];
    return switch (node) {
      JsonObject(:final fields) => JsonObject({
        ...fields,
        segment: _replaceAt(
          fields[segment] ?? const JsonNull(),
          depth + 1,
          replacement,
        ),
      }),
      JsonArray(:final items) => _replaceItem(items, depth, replacement),
      _ => node,
    };
  }

  JsonArray _replaceItem(
    List<JsonValue> items,
    int depth,
    JsonValue replacement,
  ) {
    final target = int.parse(segments[depth]);
    return JsonArray([
      for (final (index, item) in items.indexed)
        if (index == target) _replaceAt(item, depth + 1, replacement) else item,
    ]);
  }

  bool _startsInVariables(JsonValue operations) => switch (operations) {
    JsonObject() => segments.length >= 2 && segments.first == 'variables',
    JsonArray(:final items) =>
      segments.length >= 3 &&
          _indexOf(segments.first, items.length) != null &&
          segments[1] == 'variables',
    _ => false,
  };

  JsonValue? _child(JsonValue node, String segment) => switch (node) {
    JsonObject(:final fields) => fields[segment],
    JsonArray(:final items) => _itemAt(items, segment),
    _ => null,
  };

  JsonValue? _itemAt(List<JsonValue> items, String segment) {
    final index = _indexOf(segment, items.length);
    return index == null ? null : items[index];
  }

  int? _indexOf(String segment, int length) {
    if (!_index.hasMatch(segment)) return null;
    final index = int.tryParse(segment);
    return index != null && index < length ? index : null;
  }
}
```

```dart
/// The `map` field of a multipart request, validated against its
/// `operations`: which file part goes to which places.
@internal
final class UploadMap {
  /// Creates a map of [entries], in the order of the `map` field.
  const UploadMap(this.entries);

  /// The file parts the map names.
  final List<UploadMapEntry> entries;

  /// A copy of [operations] with every mapped place replaced by the token of
  /// its file, which [tokenByField] gives for each part name.
  ///
  /// A part without a token is a [StateError]: the reader has all the files
  /// before it applies the map.
  JsonValue apply(JsonValue operations, Map<String, String> tokenByField) {
    var result = operations;
    for (final UploadMapEntry(:field, :paths) in entries) {
      final token = tokenByField[field];
      if (token == null) throw StateError('No token for the part "$field".');
      for (final path in paths) {
        result = path.replace(result, JsonString(token));
      }
    }
    return result;
  }
}
```

```dart
/// Reads the `map` field of a multipart request and checks it against the
/// `operations` value (spec section 8 of M7).
///
/// The limits come first, so a map that names thousands of places costs
/// counting, not walking.
@internal
final class UploadMapParser {
  /// Creates a parser that accepts at most [maxFiles] keys and as many paths.
  const UploadMapParser(this.maxFiles);

  /// The most keys, and the most paths in total, the map may hold.
  final int maxFiles;

  static const UploadMapInvalid _malformed = UploadMapInvalid(
    DecodingRefusal(
      400,
      DiagnosticCode.malformedMultipartRequest,
      'The map field must be a JSON object of lists of paths.',
    ),
  );

  static const UploadMapInvalid _badPath = UploadMapInvalid(
    DecodingRefusal(
      400,
      DiagnosticCode.malformedMultipartRequest,
      'A map path must name a null value inside variables.',
    ),
  );

  static const UploadMapInvalid _repeatedPlace = UploadMapInvalid(
    DecodingRefusal(
      400,
      DiagnosticCode.malformedMultipartRequest,
      'Two map paths name the same place.',
    ),
  );

  /// Validates [map] against [operations], never throwing.
  UploadMapResult parse(JsonValue map, JsonValue operations) {
    if (map is! JsonObject) return _malformed;
    if (map.fields.length > maxFiles) return _tooMany('files');
    final entries = <UploadMapEntry>[];
    final places = <String>{};
    var pathCount = 0;
    for (final MapEntry(key: field, value: list) in map.fields.entries) {
      if (list is! JsonArray || list.items.isEmpty) return _malformed;
      pathCount += list.items.length;
      if (pathCount > maxFiles) return _tooMany('paths');
      final paths = <MapPath>[];
      final problem = _collect(list, operations, places, paths);
      if (problem != null) return problem;
      entries.add(UploadMapEntry(field, paths));
    }
    return UploadMapValid(UploadMap(entries));
  }

  // `places` is shared by all keys: two keys may not fill one place either.
  UploadMapInvalid? _collect(
    JsonArray list,
    JsonValue operations,
    Set<String> places,
    List<MapPath> paths,
  ) {
    for (final item in list.items) {
      if (item is! JsonString) return _malformed;
      final path = MapPath(item.value);
      if (!path.isNullIn(operations)) return _badPath;
      if (!places.add(path.place)) return _repeatedPlace;
      paths.add(path);
    }
    return null;
  }

  UploadMapInvalid _tooMany(String noun) => UploadMapInvalid(
    DecodingRefusal(
      413,
      DiagnosticCode.tooManyUploads,
      'The map may name at most $maxFiles $noun.',
    ),
  );
}
```

```dart
import 'package:typed_graphql_server/typed_graphql_server.dart';

/// A storage that wraps [MemoryUploadStorage] and counts what it is asked.
final class CountingStorage implements UploadStorage {
  CountingStorage({
    this.releaseThrows = false,
    this.chunkDelay = Duration.zero,
  });

  /// How long the storage takes to handle each chunk of a file.
  final Duration chunkDelay;

  /// Whether [release] throws after it forgot the upload.
  final bool releaseThrows;

  final UploadStorage _inner = const MemoryUploadStorage();
  final List<Upload> _held = [];

  /// How many files were stored completely.
  int stored = 0;

  /// How many files were released.
  int released = 0;

  /// How many [store] calls failed.
  int failed = 0;

  /// The names the files were stored with, in order.
  final List<String> filenames = [];

  /// The media types the files were stored with, in order.
  final List<String> mediaTypes = [];

  /// The uploads stored and not released yet.
  List<Upload> get held => List.unmodifiable(_held);

  @override
  Future<Upload> store(
    String filename,
    String mediaType,
    Stream<List<int>> content,
  ) async {
    filenames.add(filename);
    mediaTypes.add(mediaType);
    try {
      final upload = await _inner.store(
        filename,
        mediaType,
        content.asyncMap((chunk) async {
          await Future<void>.delayed(chunkDelay);
          return chunk;
        }),
      );
      stored++;
      _held.add(upload);
      return upload;
    } on Exception {
      failed++;
      rethrow;
    }
  }

  @override
  Future<void> release(Upload upload) async {
    released++;
    _held.remove(upload);
    if (releaseThrows) throw StateError('release failed');
  }
}
```

```dart
import 'dart:convert';

/// A builder of `multipart/form-data` bodies for the upload tests.
final class MultipartBody {
  MultipartBody({String boundary = 'testBoundary'})
    : this._(boundary, const []);

  MultipartBody._(this.boundary, this._parts);

  final String boundary;
  final List<List<int>> _parts;

  /// The `content-type` header of a request with this body.
  String get contentType => 'multipart/form-data; boundary=$boundary';

  /// A text field.
  MultipartBody field(String name, String value) => rawPart(
    'content-disposition: form-data; name="$name"',
    utf8.encode(value),
  );

  /// A field whose content is arbitrary bytes.
  MultipartBody fieldBytes(String name, List<int> content) =>
      rawPart('content-disposition: form-data; name="$name"', content);

  /// A file part; a null [contentType] leaves the header out.
  MultipartBody file(
    String name,
    List<int> content, {
    String? filename = 'file.txt',
    String? contentType = 'text/plain',
  }) => rawPart(
    [
      'content-disposition: form-data; name="$name"'
          '${filename == null ? '' : '; filename="$filename"'}',
      ?(contentType == null ? null : 'content-type: $contentType'),
    ].join('\r\n'),
    content,
  );

  /// A part with exactly [headers] (lines joined by CRLF, without the blank
  /// line) and [content].
  MultipartBody rawPart(String headers, List<int> content) =>
      MultipartBody._(boundary, [
        ..._parts,
        [
          ...utf8.encode('--$boundary\r\n$headers\r\n\r\n'),
          ...content,
          ...utf8.encode('\r\n'),
        ],
      ]);

  /// The whole body, with the closing delimiter.
  List<int> get bytes => [
    for (final part in _parts) ...part,
    ...utf8.encode('--$boundary--\r\n'),
  ];

  /// The body split in chunks of [chunkSize] bytes, or in one chunk when it
  /// is null.
  Stream<List<int>> stream({int? chunkSize, List<int>? source}) {
    final all = source ?? bytes;
    if (chunkSize == null) return Stream.value(all);
    return Stream.fromIterable([
      for (var start = 0; start < all.length; start += chunkSize)
        all.sublist(
          start,
          start + chunkSize > all.length ? all.length : start + chunkSize,
        ),
    ]);
  }
}

final class ConnectionReset implements Exception {
  const ConnectionReset();
}
```

```dart
import 'dart:async';

import 'package:meta/meta.dart';

import 'byte_limit_exceeded.dart';

/// Counts the bytes of one stream and fails it with [ByteLimitExceeded] when
/// they pass [limit].
///
/// An instance counts one stream: it holds the running total.
@internal
final class ByteLimit extends StreamTransformerBase<List<int>, List<int>> {
  /// Creates a limit of [limit] bytes.
  ByteLimit(this.limit);

  /// The most bytes the stream may carry.
  final int limit;

  int _count = 0;

  /// Counts [length] more bytes and tells whether the total is still within
  /// the limit.
  bool admits(int length) {
    _count += length;
    return _count <= limit;
  }

  /// Passes the chunks of [stream] through until the limit is passed; the
  /// chunk that passes it is not emitted and the source is cancelled.
  @override
  Stream<List<int>> bind(Stream<List<int>> stream) async* {
    await for (final chunk in stream) {
      if (!admits(chunk.length)) throw ByteLimitExceeded(this);
      yield chunk;
    }
  }
}
```

```dart
import 'package:meta/meta.dart';

/// The `content-disposition` header of one part of a `multipart/form-data`
/// body (RFC 7578 section 4.2): the field name and, for a file, its name.
///
/// Only `name` and `filename` are read. `filename*` (RFC 8187) is ignored, so
/// the name a browser sends in `filename` is the one used.
@internal
final class ContentDisposition {
  const ContentDisposition._(this.name, this.filename);

  /// Reads [header], or returns null when it is absent, is not `form-data`,
  /// has no `name` or is malformed.
  static ContentDisposition? parse(String? header) {
    if (header == null) return null;
    final scanner = _Scanner(header);
    if (scanner.readUntilSemicolon().toLowerCase() != 'form-data') return null;
    String? name;
    String? filename;
    while (scanner.skipSemicolon()) {
      final parameter = scanner.readParameter();
      if (parameter == null) return null;
      switch (parameter) {
        case ('name', final value):
          name ??= value;
        case ('filename', final value):
          filename ??= value;
        case _:
      }
    }
    return name == null ? null : ContentDisposition._(name, filename);
  }

  /// The field name.
  final String name;

  /// The file name the client gave, or null for a field that is not a file.
  final String? filename;
}

/// A cursor over the text of the header.
final class _Scanner {
  _Scanner(this._text);

  final String _text;
  int _position = 0;

  bool skipSemicolon() {
    if (_position >= _text.length || _text[_position] != ';') return false;
    _position++;
    return true;
  }

  String readUntilSemicolon() {
    final start = _position;
    while (_position < _text.length && _text[_position] != ';') {
      _position++;
    }
    return _text.substring(start, _position).trim();
  }

  /// The next `name=value` pair with a lower-case name, `('', '')` for a
  /// parameter without a value, or null when the value is malformed.
  (String, String)? readParameter() {
    final start = _position;
    while (_position < _text.length &&
        _text[_position] != '=' &&
        _text[_position] != ';') {
      _position++;
    }
    final name = _text.substring(start, _position).trim().toLowerCase();
    if (_position >= _text.length || _text[_position] == ';') return ('', '');
    _position++;
    final value = _readValue();
    return value == null ? null : (name, value);
  }

  String? _readValue() {
    while (_position < _text.length && _text[_position] == ' ') {
      _position++;
    }
    if (_position >= _text.length || _text[_position] != '"') {
      return readUntilSemicolon();
    }
    final value = _readQuoted();
    if (value == null) return null;
    while (_position < _text.length && _text[_position] == ' ') {
      _position++;
    }
    return _position < _text.length && _text[_position] != ';' ? null : value;
  }

  String? _readQuoted() {
    final value = StringBuffer();
    _position++;
    while (_position < _text.length) {
      final character = _text[_position++];
      if (character == '"') return value.toString();
      if (character == r'\' && _position < _text.length) {
        value.write(_text[_position++]);
      } else {
        value.write(character);
      }
    }
    return null;
  }
}
```

```dart
import 'dart:async';

import 'package:meta/meta.dart';
import 'package:mime/mime.dart';
import 'package:typed_graphql/typed_graphql.dart';

import '../http/request_decoding.dart';
import 'byte_limit.dart';

import 'multipart_result.dart';
import 'multipart_run.dart';
import 'uploads.dart';
import 'watched_body.dart';

/// Reads the body of a `multipart/form-data` request as the GraphQL multipart
/// request specification defines it (spec section 8 of M7): `operations`,
/// `map`, then the files, each file streamed into the storage of [uploads]
/// within the limits.
///
/// Whatever goes wrong with the request, the result is a refusal and nothing
/// it stored is left; whatever goes wrong with the body, the body is
/// cancelled.
@internal
final class MultipartReader {
  /// Creates a reader that stores files as [uploads] says, parses JSON nested
  /// at most [maxJsonDepth] deep and waits at most [bodyTimeout] for the
  /// whole body.
  const MultipartReader(
    this.uploads, {
    required this.maxJsonDepth,
    required this.bodyTimeout,
  });

  /// The storage and the limits.
  final Uploads uploads;

  /// The deepest nesting of arrays and objects accepted in a JSON field.
  final int maxJsonDepth;

  /// How long the whole body may take to arrive.
  final Duration bodyTimeout;

  /// Reads [body], whose parts are separated by [boundary].
  ///
  /// The package:mime parser throws on a malformed header inside the zone
  /// that calls it, not into its stream, so the read runs in a guarded zone
  /// whose errors become the failure of the body.
  Future<MultipartResult> read(Stream<List<int>> body, String boundary) {
    final watch = WatchedBody(
      body,
      ByteLimit(uploads.limits.maxRequestBytes),
      bodyTimeout,
    );
    final completer = Completer<MultipartResult>();
    runZonedGuarded(
      () => _consume(watch, boundary).then(
        completer.complete,
        onError: completer.completeError,
      ),
      (error, stack) => watch.fail(error),
    );
    return completer.future;
  }

  Future<MultipartResult> _consume(WatchedBody watch, String boundary) async {
    final run = MultipartRun(uploads, watch, maxJsonDepth);
    var isKept = false;
    try {
      final parts = MimeMultipartTransformer(boundary).bind(watch.stream);
      final result = await run.consume(parts);
      isKept = result is MultipartContent;
      return result;
    } on Exception catch (error) {
      return MultipartRefusal(_refusalFor(error));
    } finally {
      watch.cancel();
      if (!isKept) await run.stored.release();
    }
  }

  DecodingRefusal _refusalFor(Exception error) => switch (error) {
    ByteLimitExceeded() => DecodingRefusal(
      413,
      DiagnosticCode.uploadTooLarge,
      'The request body is larger than ${uploads.limits.maxRequestBytes} '
      'bytes.',
    ),
    TimeoutException() => DecodingRefusal(
      408,
      DiagnosticCode.requestBodyTimeout,
      'The request body did not arrive within ${bodyTimeout.inMilliseconds} '
      'ms.',
    ),
    MimeMultipartException() || FormatException() => const DecodingRefusal(
      400,
      DiagnosticCode.malformedMultipartRequest,
      'The multipart request is malformed.',
    ),
    _ => const DecodingRefusal(
      400,
      DiagnosticCode.malformedRequestBody,
      'The request body could not be read.',
    ),
  };
}
```

```dart
/// A refusal on its way out of [MultipartRun]: every step of the run is a
/// sequence of reads that can end the request, and this carries the reason
/// to the one place that answers it.
final class _Refused implements Exception {
  const _Refused(this.status, this.code, this.message);

  _Refused.malformed(String message)
    : this(400, DiagnosticCode.malformedMultipartRequest, message);

  final int status;
  final DiagnosticCode code;
  final String message;
}

/// One reading of the parts of a multipart request, in the order the
/// specification fixes: `operations`, `map`, then the files.
@internal
final class MultipartRun {
  /// Creates a run that stores files in [uploads], reads [watch]'s parts and
  /// parses JSON nested at most [maxJsonDepth] deep.
  MultipartRun(this._uploads, this._watch, this._maxJsonDepth)
    : stored = StoredUploads(_uploads);

  final Uploads _uploads;
  final WatchedBody _watch;
  final int _maxJsonDepth;

  /// The files stored so far, which the caller releases.
  final StoredUploads stored;

  /// Reads every part of [parts], never throwing for a request that is wrong;
  /// the failure of the body itself is thrown.
  Future<MultipartResult> consume(Stream<MimeMultipart> parts) async {
    final iterator = StreamIterator(parts);
    try {
      final operations = await _readJson(iterator, 'first', 'operations');
      final mapValue = await _readJson(iterator, 'second', 'map');
      final map = switch (UploadMapParser(
        _uploads.limits.maxFiles,
      ).parse(mapValue, operations)) {
        UploadMapValid(:final map) => map,
        UploadMapInvalid(:final refusal) => throw _Refused(
          refusal.status,
          refusal.code,
          refusal.message,
        ),
      };
      final tokens = await _readFiles(iterator, map);
      return MultipartContent(map.apply(operations, tokens), stored);
    } on _Refused catch (refused) {
      return MultipartRefusal(
        DecodingRefusal(refused.status, refused.code, refused.message),
      );
    } finally {
      await iterator.cancel();
    }
  }

  Future<JsonValue> _readJson(
    StreamIterator<MimeMultipart> iterator,
    String ordinal,
    String name,
  ) async {
    final mustBe = _Refused.malformed(
      'The $ordinal field of a multipart request must be $name.',
    );
    if (!await _watch.guard(iterator.moveNext())) throw mustBe;
    final part = iterator.current;
    if (_dispositionOf(part).name != name) throw mustBe;
    final maxBytes = _uploads.limits.maxFieldBytes;
    final limit = ByteLimit(maxBytes);
    final bytes = BytesBuilder(copy: false);
    try {
      await limit.bind(_watch.track(part)).forEach(bytes.add);
    } on ByteLimitExceeded catch (error) {
      if (!identical(error.origin, limit)) rethrow;
      throw _Refused(
        413,
        DiagnosticCode.uploadTooLarge,
        'The $name field is larger than $maxBytes bytes.',
      );
    }
    return _decodeJson(bytes.takeBytes(), name);
  }

  JsonValue _decodeJson(Uint8List bytes, String name) {
    final invalid = _Refused.malformed('The $name field is not valid JSON.');
    final String text;
    try {
      text = const Utf8Decoder().convert(bytes);
    } on FormatException {
      throw invalid;
    }
    return switch (JsonReader(maxDepth: _maxJsonDepth).parse(text)) {
      DecodeSuccess(:final value) => value,
      DecodeFailure() => throw invalid,
    };
  }

  Future<Map<String, String>> _readFiles(
    StreamIterator<MimeMultipart> iterator,
    UploadMap map,
  ) async {
    final expected = {for (final entry in map.entries) entry.field};
    final tokens = <String, String>{};
    while (await _watch.guard(iterator.moveNext())) {
      final part = iterator.current;
      final disposition = _dispositionOf(part);
      if (!expected.contains(disposition.name) ||
          tokens.containsKey(disposition.name)) {
        throw _Refused.malformed(
          'The request contains a file the map does not name.',
        );
      }
      tokens[disposition.name] = await _store(part, disposition);
    }
    if (tokens.length != expected.length) {
      throw _Refused.malformed(
        'The map names a file the request does not contain.',
      );
    }
    return tokens;
  }

  Future<String> _store(
    MimeMultipart part,
    ContentDisposition disposition,
  ) async {
    final maxBytes = _uploads.limits.maxFileBytes;
    final limit = ByteLimit(maxBytes);
    try {
      final upload = await _uploads.storage.store(
        disposition.filename ?? '',
        part.headers['content-type'] ?? 'application/octet-stream',
        limit.bind(_watch.track(part)),
      );
      return stored.add(upload);
    } on ByteLimitExceeded catch (error) {
      if (!identical(error.origin, limit)) rethrow;
      throw _Refused(
        413,
        DiagnosticCode.uploadTooLarge,
        'A file is larger than $maxBytes bytes.',
      );
    }
  }

  ContentDisposition _dispositionOf(MimeMultipart part) =>
      ContentDisposition.parse(part.headers['content-disposition']) ??
      (throw _Refused.malformed(
        'A multipart field must have a content-disposition of form-data '
        'with a name.',
      ));
}
```

```dart
import 'package:meta/meta.dart';

import 'upload.dart';
import 'uploads.dart';

/// The files one request has stored: what the registry and the storage hold
/// for it, and the means to let both go.
@internal
final class StoredUploads {
  /// Creates an empty set of files kept in the registry and storage of
  /// [uploads].
  StoredUploads(this._uploads);

  final Uploads _uploads;
  final List<(String, Upload)> _entries = [];

  /// Registers [upload] and returns the token that stands for it in the
  /// request's variables.
  String add(Upload upload) {
    final token = _uploads.registry.register(upload);
    _entries.add((token, upload));
    return token;
  }

  /// The tokens of the files, in the order they were stored.
  List<String> get tokens => [for (final (token, _) in _entries) token];

  /// The number of files stored.
  int get length => _entries.length;

  /// Forgets every token and releases every file, whatever a release does.
  Future<void> release() async {
    final entries = [..._entries];
    _entries.clear();
    _uploads.registry.remove([for (final (token, _) in entries) token]);
    for (final (_, upload) in entries) {
      try {
        await _uploads.storage.release(upload);
      } on Object {
        // A storage that fails to release must not change the response that
        // is already decided, and the other files still need their release.
      }
    }
  }
}
```

```dart
import 'dart:async';

import 'package:meta/meta.dart';
import 'package:mime/mime.dart';

import 'byte_limit.dart';
import 'byte_limit_exceeded.dart';

/// A request body that reports what goes wrong with it, so that a reader
/// waiting on a part of it never waits forever.
///
/// `package:mime` leaves three failures unreported while a part is being
/// read: the body ends in the middle of a part, the body fails, and the parser
/// throws on a bad header (that error escapes into the zone instead of the
/// stream). Each is recorded here as the one failure of the body, and
/// [guard] and [track] turn it into an error where the reader waits. The body
/// must also stop within a time limit that covers all of it, and a failure
/// cancels the host's subscription, which a paused parser would never do.
@internal
final class WatchedBody {
  /// Creates the watch over [source], which may carry [limit] bytes and must
  /// arrive within [timeout].
  WatchedBody(this._source, this._limit, this._timeout);

  final Stream<List<int>> _source;
  final ByteLimit _limit;
  final Duration _timeout;
  final Completer<Object> _failure = Completer<Object>();
  // `late`: the callbacks are methods of this object, which a field
  // initializer may not name before the object exists.
  late final StreamController<List<int>> _controller =
      StreamController<List<int>>(
        onListen: _start,
        onPause: () => _subscription?.pause(),
        onResume: () => _subscription?.resume(),
        onCancel: cancel,
      );
  StreamSubscription<List<int>>? _subscription;
  Timer? _timer;
  bool _isPartOpen = false;

  /// The bytes of the body, within the limit.
  Stream<List<int>> get stream => _controller.stream;

  /// Waits for [work], or fails with the failure of the body if that comes
  /// first.
  Future<T> guard<T>(Future<T> work) => Future.any<T>([
    work,
    _failure.future.then<T>(Future<T>.error),
  ]);

  /// Records [error] as the failure of the body and stops reading it.
  void fail(Object error) {
    if (_failure.isCompleted) return;
    _failure.complete(error);
    cancel();
  }

  /// Stops reading the host's body and its time limit; calling it again does
  /// nothing.
  void cancel() {
    _timer?.cancel();
    _subscription?.cancel().ignore();
  }

  /// Forwards the bytes of [part] and fails with the body's failure if it
  /// comes before the part ends.
  Stream<List<int>> track(Stream<List<int>> part) {
    _isPartOpen = true;
    return _forward(part);
  }

  Stream<List<int>> _forward(Stream<List<int>> part) async* {
    final iterator = StreamIterator(part);
    try {
      while (await guard(iterator.moveNext())) {
        yield iterator.current;
      }
      _isPartOpen = false;
    } finally {
      await iterator.cancel();
    }
  }

  void _start() {
    _timer = Timer(_timeout, () => fail(TimeoutException(null, _timeout)));
    _subscription = _source.listen(
      _onChunk,
      onError: fail,
      onDone: _onSourceDone,
      cancelOnError: true,
    );
  }

  void _onChunk(List<int> chunk) {
    if (_failure.isCompleted) return;
    if (_limit.admits(chunk.length)) {
      _controller.add(chunk);
    } else {
      fail(ByteLimitExceeded(_limit));
    }
  }

  // The part that ends the body closes in the same parse step that sees the
  // last bytes, but the reader learns of it a few microtasks later, so the
  // check waits for the event loop: a part still open then never ends.
  void _onSourceDone() {
    _timer?.cancel();
    _controller.close().ignore();
    Timer.run(() {
```

### Task 5: feat(typed_graphql_server): accept uploads in GraphQLHttpHandler

**Why.** One `Uploads` value wires both sides, so the handler takes it through `HttpOptions.uploads`. `multipart/form-data` is a type a browser sends cross-site without a preflight, so the CSRF check runs in the transport before the body is read (deviation 8); the boundary and `content-length` are checked before the reader starts; the files are released in a `finally` after the response is built.

```dart
  const MultipartPost(this.options, this.uploads, this.csrfPrevention);

  /// The depth and time limits to apply.
  final HttpOptions options;

  /// The storage and the size limits.
  final Uploads uploads;

  /// The rule a request passes before its body is read, or null.
  final CsrfPrevention? csrfPrevention;

  /// Whether [request] says its body is `multipart/form-data`.
  bool isMultipart(HttpRequestData request) =>
      ContentType.parse(request.header('content-type'))?.mediaType ==
      'multipart/form-data';

  /// Reads the body of [request]; the body is not touched when the CSRF rule,
  /// the boundary or the declared length already refuse the request.
  ///
  /// The rule runs here as well as in the pipeline because a forged
  /// cross-site form must not cost a single file write (deviation 8).
  Future<MultipartResult> read(HttpRequestData request) {
    final prevention = csrfPrevention;
    if (prevention != null && !prevention.allows(_info(request))) {
      return _refused(
        403,
        DiagnosticCode.csrfRequestBlocked,
        prevention.refusal,
      );
    }
    final boundary = ContentType.parse(
      request.header('content-type'),
    )?.parameters['boundary'];
    if (boundary == null || boundary.isEmpty) {
      return _refused(
        400,
        DiagnosticCode.malformedMultipartRequest,
        'The multipart request has no boundary.',
      );
    }
    final length = int.tryParse(request.header('content-length')?.trim() ?? '');
    final maxBytes = uploads.limits.maxRequestBytes;
    if (length != null && length > maxBytes) {
      return _refused(
        413,
        DiagnosticCode.uploadTooLarge,
        'The request body is larger than $maxBytes bytes.',
      );
    }
    return MultipartReader(
      uploads,
      maxJsonDepth: options.maxJsonDepth,
      bodyTimeout: options.bodyTimeout,
    ).read(request.body, boundary);
  }

  RequestInfo _info(HttpRequestData request) => RequestInfo(
    method: request.method,
    uri: request.uri,
    headers: request.headers,
    source: request.source,
  );

  Future<MultipartResult> _refused(
    int status,
    DiagnosticCode code,
    String message,
  ) async => MultipartRefusal(DecodingRefusal(status, code, message));
}
```

+## Limits
+
+`UploadLimits` has safe defaults and every refusal is a transport error
+before the pipeline, so no context is built and no resolver runs:
+
+- `maxRequestBytes` (20 MiB) bounds the whole body, by `content-length`
+  first and by a running count of the bytes that arrive, and `413` `GQL441`
+  refuses more. The body must also arrive within `HttpOptions.bodyTimeout`
+  (`408`, `GQL427`).
+- `maxFieldBytes` (1 MiB) bounds each of `operations` and `map`; the JSON is
+  parsed with `HttpOptions.maxJsonDepth`, and a field that is not valid JSON is
+  `400` `GQL440`.
+- `maxFileBytes` (5 MiB) bounds each file; the file is cut off while it
+  streams, the storage drops what it wrote, and the answer is `413` `GQL441`.
+- `maxFiles` (10) bounds the keys of the map and, separately, the paths it
+  names; more is `413` `GQL442`, so one part named by many paths cannot
+  multiply a request.
+
+Anything else wrong with the structure is `400` `GQL440`: no boundary,
+`operations` and `map` out of order, a map that is not an object of lists of
+paths, a path that does not name a `null` inside `variables`, a part the map
+does not name, a file the map names that never arrives, a malformed part.
+

+
+A browser sends `multipart/form-data` across sites without a preflight, so
