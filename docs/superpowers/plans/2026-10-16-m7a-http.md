# M7a GraphQL over HTTP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the first part of stage M7 in `typed_graphql_server`: GraphQL over HTTP (R5.5, R5.12). `GraphQLHttpHandler.handle(HttpRequestData)` turns any host's request into an `HttpResponseData` and never throws: method, URI length, `Accept` negotiation (`application/graphql-response+json`, `application/json`), GET parameters, POST content type, a body read within a size and a time limit, strict UTF-8 JSON with a depth limit, the request run through `GraphQLServer.handle` with only queries and mutations allowed, and the status codes of the GraphQL-over-HTTP specification (`294` for partial success, the legacy `application/json` watershed). Batching is an opt-in `BatchPolicy` with a shared `CostBudget`. It adds `GQL420`-`GQL431` to the core catalog, the pipeline refinements of spec section 7 (`GraphQLServer.profile`, `ServerRequest.allowedOperationTypes`, `ServerRequest.costBudget`), the hostile-input tests and the HTTP guide.

**Architecture:** The HTTP values (`HttpRequestData`, `HttpResponseData`, the sealed `HttpResponseBody`) are plain classes any adapter fills (shelf in M7e, grund later), so the server package stays free of `dart:io`. Everything lives in the server's new `lib/src/http/` (dartdoc category `http`, guide `doc/http.md`): `AcceptNegotiation` over `MediaRange` picks the response type; `ContentType` parses the request's; `BodyReader` counts bytes as they arrive and times the whole body; `RequestDecoding` (`GetParameters`, `JsonBodyDecoder`) turns a request into a `DecodedRequest`, a `DecodedBatch` or a `DecodingRefusal`; `ResultWriter` with `StatusTable` writes a `ServerResponse`, and `TransportErrors` writes the refusals that come before the pipeline as `application/json`. `GraphQLHttpHandler` composes them in the order of spec section 4; `BatchRunner` runs a batch's items one by one under one `CostBudget`.

**Tech Stack:** Dart 3.13 (formatted with the 3.47.6 Flutter SDK's Dart 3.13.5), `package:test`, `package:meta`; no new dependency (`dart:typed_data` joins the server's allowed imports in Task 6).

**Spec:** `docs/superpowers/specs/2026-10-16-m7-transports-design.md` (sections 3-7, 13, 14, 15 and 17), `docs/requirements.md` (R0.3, R5.5, R5.12, R5.14), the specification `reference/graphql-over-http/spec/GraphQLOverHTTP.md`.

**Base:** `main` with the M7 spec (the tree of `m7-plan` at `0274818`). It is generated from the commits that implemented it in a scratch copy, in order.

**Parallel work:** M7a is the first plan of the main M7 line (M7a, M7b, M7d, M7e run one after another on one branch). M7c (graphql-ws) runs in parallel on its own branch from the same base; the two share `packages/typed_graphql/lib/src/diagnostics/diagnostic_code.dart`, `packages/typed_graphql/CHANGELOG.md`, and in the server `lib/typed_graphql_server.dart`, `CHANGELOG.md` and `dartdoc_options.yaml`. ## Review Focus

1. The order of checks is spec section 4's: URI length, method, `Accept`, GET parameters or POST content type, `content-length`, the body read (size, then time), UTF-8 and JSON, the request shape; nothing reads the body before the cheaper checks pass, and every refusal has its code and status.
2. `BodyReader` counts the bytes that arrive (a lying or absent `content-length` changes nothing), stops at the first chunk past the limit, cancels the subscription in every outcome but the end, and its timer covers the whole body.
3. The status table: `294` only under `application/graphql-response+json` and only when the option is on; `400` for a `GQL0xx` request error, `403` for CSRF, `422` for the other request errors; a legacy `application/json` client gets the same codes but always `application/json`; transport refusals are never `application/graphql-response+json`.
4. `allowedOperationTypes` is checked after the GET-mutation guard and before the cost limit and the context factory; a subscription over HTTP JSON is `GQL431` with `422`, and no context is built.
5. A batch is refused whole (`GQL428`, `GQL429`, `GQL425` with the item's index) before any item runs; items run sequentially and share one `CostBudget`, so the sum is limited (`GQL430`) as well as each item (`GQL238`).
6. No message echoes request content (a header value, a parameter, a body fragment).

### Task 2: feat(typed_graphql_server): let a request restrict its operation types

**Why.** GraphQL over HTTP carries no subscriptions over a JSON response, and a batch item may be refused mutations: the transport must restrict a request's operation types inside the pipeline, after the operation is selected and before any context is built (spec section 7). The handler also needs the server's profile (CSRF pre-check in M7b, GraphiQL in M7e).

**Consumes:** M6's `ServerRequest`, `RequestStep`, `PipelineErrors`.

```dart
import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

/// The cost spent so far by the requests that share one cost limit, such as
/// the items of an HTTP batch (R5.14).
///
/// Give the same budget to the `ServerRequest`s that must stay under one
/// `maxCost` together; a request charges it only when it is within the limit
/// alone and with what the others spent.
///
/// {@category server}
final class CostBudget {
  /// Creates an empty budget.
  CostBudget();

  double _fieldCost = 0;
  double _typeCost = 0;

  /// The field cost of the requests charged so far.
  double get fieldCost => _fieldCost;

  /// The type cost of the requests charged so far.
  double get typeCost => _typeCost;

  /// Whether [cost] added to what was spent keeps both sums within
  /// [maxCost].
  @internal
  bool admits(OperationCost cost, double maxCost) =>
      // Written as `<=` so that a NaN never passes.
      _fieldCost + cost.fieldCost <= maxCost &&
      _typeCost + cost.typeCost <= maxCost;

  /// Adds [cost] to what was spent.
  @internal
  void charge(OperationCost cost) {
    _fieldCost += cost.fieldCost;
    _typeCost += cost.typeCost;
  }
}
```

````markdown
# HTTP

`GraphQLHttpHandler` serves GraphQL over HTTP on top of a `GraphQLServer`
(R5.5). It knows no web framework: a host adapter converts its own request
into an `HttpRequestData`, calls the handler and writes the
`HttpResponseData` it gets back. This guide describes the values the two
sides exchange.

## The values

An `HttpRequestData` holds the method, the full URI, the headers (names are
lower-cased), the body as a stream of byte chunks, and optionally the host's
own request object and a `CancelSignal` the host cancels when the client goes
away. The body is a stream so that the handler can stop reading at its size
limit; a host that has the bytes passes `Stream.value(bytes)`.

An `HttpResponseData` holds a status, headers and a body. The body is a
`FixedBody` (all bytes known) or a `StreamedBody` (chunks written as they
come).

```dart
import 'dart:convert';

import 'package:typed_graphql_server/typed_graphql_server.dart';

void main() {
  final request = HttpRequestData(
    method: 'POST',
    uri: Uri.parse('http://localhost/graphql'),
    headers: {'Content-Type': 'application/json'},
    body: Stream.value(utf8.encode('{"query":"{ hello }"}')),
  );
  final response = HttpResponseData(
    200,
    headers: {'Content-Type': 'application/json'},
    body: FixedBody(utf8.encode('{"data":{"hello":"Hello"}}')),
  );
  print(request.header('CONTENT-TYPE'));
  print(response.headers['content-type']);
  print(response.status);
}
```

It prints:

```text
application/json
application/json
200
```
````

```dart
import 'dart:async';

import '../cancellation/cancel_signal.dart';
import '../server/header_names.dart';

/// One HTTP request as a host hands it to `GraphQLHttpHandler`, without any
/// tie to a web framework (R5.5).
///
/// {@category http}
final class HttpRequestData {
  /// Creates a request.
  ///
  /// [headers] names are lower-cased and repeated values should already be
  /// joined with `, `. [body] is read at most once, and only when the
  /// handler needs it. [source] is the host's own request object, which the
  /// library never reads.
  HttpRequestData({
    required this.method,
    required this.uri,
    Map<String, String> headers = const {},
    this.body = const Stream<List<int>>.empty(),
    this.source,
    this.cancelSignal,
  }) : headers = const HeaderNames().lowerCased(headers);

  /// The HTTP method as the host gave it; the handler compares it ignoring
  /// case.
  final String method;

  /// The full URI, query string included.
  final Uri uri;

  /// The headers, unmodifiable, with lower-case names.
  final Map<String, String> headers;

  /// The body, a stream so the handler can stop reading at its size limit;
  /// a host that has the bytes passes `Stream.value(bytes)`.
  final Stream<List<int>> body;

  /// The host's own request object, never read by the library.
  final Object? source;

  /// Cancelled by the host when the client goes away, so the handler can stop
  /// the work nobody waits for.
  final CancelSignal? cancelSignal;

  /// The value of the header [name], whatever its case, or null.
  String? header(String name) => headers[name.toLowerCase()];
}
```

```dart
/// The body of an `HttpResponseData`: a [FixedBody] or a [StreamedBody].
///
/// {@category http}
sealed class HttpResponseBody {
  /// Creates a body.
  const HttpResponseBody();
}

/// A body whose bytes are all known.
///
/// {@category http}
final class FixedBody extends HttpResponseBody {
  /// Creates a body of [bytes], which the handler never changes afterwards.
  const FixedBody(this.bytes);

  /// The bytes to write.
  final List<int> bytes;
}

/// A body written as it comes, such as an event stream.
///

/// subscription when the client goes away.
///
/// {@category http}
final class StreamedBody extends HttpResponseBody {
  /// Creates a body of [chunks].
  const StreamedBody(this.chunks);

  /// The chunks to write, in order.
  final Stream<List<int>> chunks;
}
```

```dart
  /// Creates the negotiation over the [offered] types, in the server's order
  /// of preference.
  const AcceptNegotiation(this.offered);

  /// The types the server can write, most preferred first.
  final List<ResponseMediaType> offered;

  /// The offered type [accept] likes best, or null when it allows none.
  ///
  /// A missing or blank header gives [ResponseMediaType.json], the
  /// legacy-safe choice, when it is offered. Each offered type takes the
  /// quality of the most specific range that matches it; the highest quality
  /// above 0 wins and a tie goes to the earlier offered type. The header is
  /// split on every comma, so a comma inside a quoted parameter splits
  /// wrongly; that range is then ignored as invalid.
  ResponseMediaType? choose(String? accept) {
    if (accept == null || accept.trim().isEmpty) {
      return offered.contains(ResponseMediaType.json)
          ? ResponseMediaType.json
          : null;
    }
    final ranges = [
      for (final element in accept.split(',')) ?MediaRange.parse(element),
    ];
    ResponseMediaType? best;
    var bestQuality = 0.0;
    for (final candidate in offered) {
      final quality = _qualityOf(candidate, ranges);
      if (quality > bestQuality) {
        best = candidate;
        bestQuality = quality;
      }
    }
    return best;
  }

  double _qualityOf(ResponseMediaType candidate, List<MediaRange> ranges) {
    var specificity = -1;
    var quality = 0.0;
    for (final range in ranges) {
      final match = range.specificityFor(candidate);
      if (match == null || match < specificity) continue;
      if (match > specificity) quality = 0;
      specificity = match;
      if (range.quality > quality) quality = range.quality;
    }
    return quality;
  }
}
```

```dart
import 'package:meta/meta.dart';

/// The parsed `content-type` header of a request: a media type and its
/// parameters.
@internal
final class ContentType {
  /// Creates a content type of [mediaType] (`type/subtype`, lower-case) with
  /// [parameters], whose names are lower-case and values unquoted.
  const ContentType(this.mediaType, this.parameters);

  /// `type/subtype`, lower-case.
  final String mediaType;

  /// The parameters by lower-case name; a repeated name keeps its last value.
  final Map<String, String> parameters;

  /// The lower-cased `charset` parameter, or null.
  String? get charset => parameters['charset']?.toLowerCase();

  /// The content type in [header], or null when it is missing or malformed
  /// (no `type/subtype`, a parameter without a value, an unterminated quote).
  static ContentType? parse(String? header) {
    if (header == null) return null;
    final segments = _split(header);
    if (segments == null) return null;
    final name = segments.first.trim().toLowerCase();
    final halves = name.split('/');
    if (halves.length != 2 || halves.any((half) => half.isEmpty)) return null;
    if (name.contains(RegExp(r'\s'))) return null;
    final parameters = <String, String>{};
    for (final segment in segments.skip(1)) {
      if (segment.trim().isEmpty) continue;
      final parameter = _parameter(segment);
      if (parameter == null) return null;
      parameters[parameter.$1] = parameter.$2;
    }
    return ContentType(name, Map.unmodifiable(parameters));
  }

  // Splits at the `;` outside quotes; null for an unterminated quote.
  static List<String>? _split(String header) {
    final segments = <String>[];
    final current = StringBuffer();
    var isQuoted = false;
    var isEscaped = false;
    for (final unit in header.split('')) {
      if (isEscaped) {
        isEscaped = false;
      } else if (isQuoted && unit == r'\') {
        isEscaped = true;
      } else if (unit == '"') {
        isQuoted = !isQuoted;
      } else if (unit == ';' && !isQuoted) {
        segments.add(current.toString());
        current.clear();
        continue;
      }
      current.write(unit);
    }
    segments.add(current.toString());
    return isQuoted ? null : segments;
  }

  static (String, String)? _parameter(String segment) {
    final index = segment.indexOf('=');
    if (index < 0) return null;
    final name = segment.substring(0, index).trim().toLowerCase();
    final value = _value(segment.substring(index + 1).trim());
    return name.isEmpty || value == null ? null : (name, value);
  }

  // A token as written, or a quoted string without its quotes and escapes;
  // null for text after the closing quote.
  static String? _value(String text) {
    if (!text.startsWith('"')) return text;
    final value = StringBuffer();
    var isEscaped = false;
    for (var i = 1; i < text.length; i++) {
      final unit = text[i];
      if (isEscaped) {
        value.write(unit);
        isEscaped = false;
      } else if (unit == r'\') {
        isEscaped = true;
      } else if (unit == '"') {
        return text.substring(i + 1).trim().isEmpty ? value.toString() : null;
      } else {
        value.write(unit);
      }
    }
    return null;
  }
}
```

```dart
import 'package:meta/meta.dart';

import 'response_media_type.dart';

/// One element of an `Accept` header: a media range and its quality (RFC 9110
/// section 12.5.1).
@internal
final class MediaRange {
  /// Creates a range of [type] and [subtype], either of which may be `*`.
  const MediaRange(this.type, this.subtype, this.quality);

  /// The top-level type, lower-case, or `*`.
  final String type;

  /// The subtype, lower-case, or `*`.
  final String subtype;

  /// The weight of the range, from 0 (excluded) to 1.
  final double quality;

  // The grammar of a `qvalue`: at most three decimals, nothing above 1.
  static final RegExp _quality = RegExp(
    r'^(?:0(?:\.\d{0,3})?|1(?:\.0{0,3})?)$',
  );

  /// The range of one comma-separated [element], or null when it is invalid
  /// (a missing slash, an empty part, a `q` that is not a number from 0 to 1
  /// with at most three decimals), so the caller ignores it.
  ///
  /// Parameters other than `q` are ignored.
  static MediaRange? parse(String element) {
    final parts = element.split(';');
    final name = parts.first.trim().toLowerCase().split('/');
    if (name.length != 2) return null;
    final [type, subtype] = name;
    if (!_isToken(type) || !_isToken(subtype)) return null;
    if (type == '*' && subtype != '*') return null;
    final quality = _qualityOf(parts.skip(1));
    return quality == null ? null : MediaRange(type, subtype, quality);
  }

  /// How closely this range names [offered]: 2 for the exact type, 1 for
  /// `type/*`, 0 for `*/*`, null when it does not match.
  int? specificityFor(ResponseMediaType offered) {
    if (type == '*') return 0;
    if (type != offered.type) return null;
    if (subtype == '*') return 1;
    return subtype == offered.subtype ? 2 : null;
  }

  static bool _isToken(String text) =>
      text.isNotEmpty && !text.contains(RegExp(r'\s'));

  // The weight given by the first `q` parameter, 1 without one, null when it
  // is malformed.
  static double? _qualityOf(Iterable<String> parameters) {
    for (final parameter in parameters) {
      final pair = parameter.split('=');
      if (pair.first.trim().toLowerCase() != 'q') continue;
      final value = pair.length == 2 ? pair[1].trim() : '';
      return _quality.hasMatch(value) ? double.tryParse(value) : null;
    }
    return 1;
  }
}
```

```dart
import 'dart:async';
import 'dart:typed_data';

import 'package:meta/meta.dart';

import 'body_read_result.dart';

/// Reads a request body into memory without ever holding more than a limit,
/// and without waiting longer than another (R5.5).
///
/// A `content-length` header can lie or be absent, so the count is of the
/// bytes that actually arrive; a client that trickles bytes is stopped by the
/// time limit, which covers the whole body, not each chunk.
@internal
final class BodyReader {
  /// Creates a reader that accepts at most [maxBytes] bytes arriving within
  /// [timeout].
  const BodyReader(this.maxBytes, this.timeout);

  /// The longest body accepted, in bytes.
  final int maxBytes;

  /// How long the whole body may take to arrive.
  final Duration timeout;

  /// Reads [body] to its end, or until a limit or an error stops it; the
  /// subscription is cancelled in every case but the end.
  Future<BodyReadResult> read(Stream<List<int>> body) =>
      _BodyRead(maxBytes, timeout).run(body);
}

/// One run of [BodyReader.read]: the state it needs, kept out of the reader
/// so the reader stays a constant.
final class _BodyRead {
  _BodyRead(this._maxBytes, this._timeout);

  final int _maxBytes;
  final Duration _timeout;
  final Completer<BodyReadResult> _completer = Completer<BodyReadResult>();
  final BytesBuilder _bytes = BytesBuilder(copy: false);
  // `late`: assigned by `run` right after the stream is listened to; no
  // callback can run before `run` returns, because events are asynchronous.
  late final StreamSubscription<List<int>> _subscription;
  Timer? _timer;

  Future<BodyReadResult> run(Stream<List<int>> body) {
    _timer = Timer(_timeout, () => _finish(const BodyTimedOut()));
    _subscription = body.listen(
      _onChunk,
      onError: (Object _) => _finish(const BodyFailed()),
      onDone: () => _finish(BodyBytes(_bytes.takeBytes())),
      cancelOnError: true,
    );
    return _completer.future;
  }

  void _onChunk(List<int> chunk) {
    if (_bytes.length + chunk.length > _maxBytes) {
      _finish(const BodyTooLarge());
      return;
    }
    _bytes.add(chunk);
  }

  void _finish(BodyReadResult result) {
    if (_completer.isCompleted) return;
    _timer?.cancel();
    _subscription.cancel().ignore();
    _completer.complete(result);
  }
}
```

```dart
import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

import '../server/server_outcome.dart';
import '../server/server_response.dart';
import 'response_media_type.dart';

/// The HTTP status of a pipeline result (spec section 5; GraphQL over HTTP
/// "Status Codes").
@internal
final class StatusTable {
  /// Creates the table; with [usesPartialSuccessStatus] off, a result with
  /// data and errors is `200` even for `application/graphql-response+json`.
  const StatusTable({required this.usesPartialSuccessStatus});

  /// Whether a result with errors gets `294` under
  /// `application/graphql-response+json`.
  final bool usesPartialSuccessStatus;

  /// The status of [response] written as [type].
  int of(SingleResponse response, ResponseMediaType type) =>
      switch (response.outcome) {
        ServerOutcome.executed => _executed(response.payload, type),
        ServerOutcome.requestError => _requestError(response.payload),
        ServerOutcome.methodNotAllowed => 405,
        ServerOutcome.internalError => 500,
      };

  // A legacy client keeps 200 whatever the result (deviation 6).
  int _executed(ResponsePayload payload, ResponseMediaType type) =>
      payload.errors.isNotEmpty &&
          usesPartialSuccessStatus &&
          type == ResponseMediaType.graphqlResponseJson
      ? 294
      : 200;

  // `GQL0xx`: the document does not parse; `GQL403`: CSRF prevention.
  int _requestError(ResponsePayload payload) {
    final code = switch (payload.errors) {
      [GraphQLError(extensions: JsonObject(:final fields)), ...] =>
        fields['code'],
      _ => null,
    };
    if (code is! JsonString) return 422;
    if (code.value.startsWith('GQL0')) return 400;
    return code.value == DiagnosticCode.csrfRequestBlocked.id ? 403 : 422;
  }
}
```

```dart
/// Makes the responses of a refusal the transport itself decides, before or
/// instead of the pipeline.
///
/// A transport refusal is not a well-formed GraphQL-over-HTTP response, so it
/// is always `application/json`, never `application/graphql-response+json`
/// (spec section 5).

  /// [maskErrors] is on.
  const TransportErrors(this.maskErrors);

  /// Whether an unexpected error is replaced by a generic message.
  final bool maskErrors;

  /// A response with [status] and one error coded [code], with [headers] such
  /// as `allow` added.
  HttpResponseData refusal(
    int status,
    DiagnosticCode code,
    String message, {
    Map<String, String> headers = const {},

    status,
    headers: const HeaderNames().merged(headers, {
      'content-type': ResponseMediaType.json.contentType,
    }),
    body: FixedBody(
      const JsonBytes().of(
        RequestErrorResult(
          errors: [
            GraphQLError(
              message,
              extensions: JsonObject({'code': JsonString(code.id)}),
            ),
          ],
        ).toJson(),
      ),
    ),
  );

  /// The `500` for a bug in the handler: `GQL330`, with the message of
  /// [error] unless errors are masked.
  HttpResponseData unexpected(Object error) => refusal(

    DiagnosticCode.unexpectedError,
    maskErrors ? const MaskedMessage().text : _describe(error),
  );

  String _describe(Object error) {
    try {
      return error.toString();
    } on Object {
      return const MaskedMessage().text;
    }
  }
```

```dart
/// Words a [DecodeFailure] for a message: its text and, when it has one, the
/// path of the value it is about.
@internal
final class FailureDescription {
  /// Creates the describer.
  const FailureDescription();

  /// The message of [failure], followed by ` at <path>` with the path's
  /// segments joined by `.`, indexes as numbers.
  String of(DecodeFailure failure) {
    if (failure.path.isEmpty) return failure.message;
    final path = failure.path
        .map(
          (segment) => switch (segment) {
            PathKey(:final name) => name,
            PathIndex(:final index) => '$index',
          },
        )
        .join('.');
    return '${failure.message} at $path';
  }
}
```

```dart
import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

import 'request_decoding.dart';

/// Reads the GraphQL parameters of a `GET` request from its query string
/// (spec section 4, step 4).
@internal
final class GetParameters {
  /// Creates a reader that accepts `variables` and `extensions` nested at most
  /// [maxJsonDepth] deep.
  const GetParameters(this.maxJsonDepth);

  /// The deepest nesting of arrays and objects accepted in a JSON parameter.
  final int maxJsonDepth;

  /// Decodes the query string of [uri], never throwing.
  ///
  /// Only `query`, `operationName`, `variables` and `extensions` are read; an
  /// empty value is absent, and a parameter given twice is refused, because
  /// two proxies could read different ones.
  RequestDecoding decode(Uri uri) {
    final Map<String, List<String>> all;
    try {
      all = uri.queryParametersAll;
    } on FormatException {
      return _refusal('The query string is not valid UTF-8.');
    }
    for (final name in _names) {
      if ((all[name]?.length ?? 0) > 1) {
        return _refusal('The parameter $name is given more than once.');
      }
    }
    return _decodeObjects(
      query: _value(all, 'query'),
      operationName: _value(all, 'operationName'),
      variables: _value(all, 'variables'),
      extensions: _value(all, 'extensions'),
    );
  }

  static const List<String> _names = [
    'query',
    'operationName',
    'variables',
    'extensions',
  ];

  String? _value(Map<String, List<String>> all, String name) {
    final value = all[name]?.single;
    return value == null || value.isEmpty ? null : value;
  }

  RequestDecoding _decodeObjects({
    required String? query,
    required String? operationName,
    required String? variables,
    required String? extensions,
  }) => switch ((
    _object('variables', variables),
    _object('extensions', extensions),
  )) {
    (DecodeFailure(:final message), _) ||
    (_, DecodeFailure(:final message)) => _refusal(message),
    (
      DecodeSuccess(value: final parsedVariables),
      DecodeSuccess(value: final parsedExtensions),
    ) =>
      DecodedRequest(
        GraphQLRequest(
          query: query,
          operationName: operationName,
          variables: parsedVariables,
          extensions: parsedExtensions,
        ),
      ),
  };

  // The object a JSON parameter holds; null for an absent parameter.
  DecodeResult<JsonObject?> _object(String name, String? text) {
    if (text == null) return const DecodeSuccess(null);
    return switch (JsonReader(maxDepth: maxJsonDepth).parse(text)) {
      DecodeSuccess(value: final JsonObject object) => DecodeSuccess(object),
      DecodeSuccess() => DecodeFailure(
        'The parameter $name is not a JSON object.',
      ),
      DecodeFailure(:final message) => DecodeFailure(
        'The parameter $name is not valid JSON: $message.',
      ),
    };
  }

  DecodingRefusal _refusal(String message) => DecodingRefusal(
    422,
    DiagnosticCode.malformedRequestParameters,
    message,
  );
}
```

```dart
/// Turns the bytes of a `application/json` POST body into a request, a batch
/// or a refusal (spec section 4, steps 7 and 8).
@internal
final class JsonBodyDecoder {
  /// Creates a decoder that accepts JSON nested at most [maxJsonDepth] deep.
  const JsonBodyDecoder({required this.maxJsonDepth});

  /// The deepest nesting of arrays and objects accepted.
  final int maxJsonDepth;

  /// Decodes [bytes], never throwing.
  RequestDecoding decode(Uint8List bytes) {
    // JSON forbids a byte-order mark (RFC 8259 section 8.1), and the UTF-8
    // decoder would drop it silently, so it is looked for in the bytes.
    if (_hasByteOrderMark(bytes)) {
      return const DecodingRefusal(
        400,
        DiagnosticCode.malformedRequestBody,
        'The request body is not valid JSON: it starts with a byte-order '
        'mark.',
      );
    }
    final String text;
    try {
      text = const Utf8Decoder().convert(bytes);
    } on FormatException {
      return const DecodingRefusal(
        400,
        DiagnosticCode.malformedRequestBody,
        'The request body is not valid UTF-8.',
      );
    }
    return switch (JsonReader(maxDepth: maxJsonDepth).parse(text)) {
      DecodeSuccess(:final value) => _decodeValue(value),
      DecodeFailure(:final message) => DecodingRefusal(
        400,
        DiagnosticCode.malformedRequestBody,
        'The request body is not valid JSON: $message.',
      ),
    };
  }

  bool _hasByteOrderMark(Uint8List bytes) =>
      bytes.length >= 3 &&
      bytes[0] == 0xEF &&
      bytes[1] == 0xBB &&
      bytes[2] == 0xBF;

  RequestDecoding _decodeValue(JsonValue value) => switch (value) {
    JsonObject() => _decodeRequest(value),
    JsonArray() => const DecodingRefusal(
      422,
      DiagnosticCode.batchingDisabled,
      'Batched requests are not enabled.',
    ),
    _ => const DecodingRefusal(
      422,
      DiagnosticCode.malformedRequestParameters,
      'The request body must be a JSON object.',
    ),
  };

  RequestDecoding _decodeRequest(JsonObject object) =>
      switch (GraphQLRequest.decode(object)) {
        DecodeSuccess(:final value) => DecodedRequest(value),
        DecodeFailure() && final failure => DecodingRefusal(
          422,
          DiagnosticCode.malformedRequestParameters,
          'The request is malformed: ${const FailureDescription().of(failure)}',
        ),
      };
}
```

```dart
/// Serves GraphQL over HTTP on top of a [GraphQLServer], for any web
/// framework: the host converts its request into an [HttpRequestData], calls
/// [handle] and writes the [HttpResponseData] it gets back (R5.5).
///
/// The handler decodes `GET` and `POST` requests, negotiates the media type
/// and writes results with the status codes of the GraphQL over HTTP
/// specification. Routing, CORS and the time headers take to arrive are the
/// host's.
///
/// {@category http}
final class GraphQLHttpHandler<C> {
  /// Creates a handler that sends requests to [server].
  ///
  /// Throws an `ArgumentError` naming the option when [options] holds a limit
  /// that makes no sense.
  GraphQLHttpHandler(this.server, {this.options = const HttpOptions()})
    : _errors = TransportErrors(server.profile.maskErrors),
      _exchange = JsonExchange<C>(
        server,
        ResultWriter(
          usesPartialSuccessStatus: options.usesPartialSuccessStatus,
        ),
      ) {
    const HttpOptionsCheck().check(options);
  }

  /// The pipeline requests are sent to.
  final GraphQLServer<C> server;

  /// The limits and settings of the handler.
  final HttpOptions options;

  final TransportErrors _errors;
  final JsonExchange<C> _exchange;

  static const List<ResponseMediaType> _offered = [
    ResponseMediaType.graphqlResponseJson,
    ResponseMediaType.json,
  ];

  /// Answers [request]; it never throws, so a host can always write what it
  /// returns.
  Future<HttpResponseData> handle(HttpRequestData request) async {
    try {
      return await _handle(request);
    } on Object catch (error) {
      // The outermost boundary: a bug anywhere below must still be a response.
      return _errors.unexpected(error);
    }
  }

  Future<HttpResponseData> _handle(HttpRequestData request) async {
    if (request.uri.toString().length > options.maxUriLength) {
      return _errors.refusal(
        414,
        DiagnosticCode.requestUriTooLong,
        'The request URI is longer than ${options.maxUriLength} characters.',
      );
    }
    final method = request.method.toUpperCase();
    if (method != 'GET' && method != 'POST') {
      return _errors.refusal(
        405,
        DiagnosticCode.unsupportedHttpMethod,
        'Only GET and POST requests are supported.',
        headers: const {'allow': 'GET, POST'},
      );
    }
    final type = const AcceptNegotiation(_offered).choose(
      request.header('accept'),
    );
    if (type == null) {
      return _errors.refusal(
        406,
        DiagnosticCode.notAcceptable,
        'The Accept header allows none of application/graphql-response+json '
        'and application/json.',
      );
    }
    final decoding = method == 'GET'
        ? GetParameters(options.maxJsonDepth).decode(request.uri)
        : await PostBody(options).decode(request);
    return _answer(request, decoding, type);
  }

  Future<HttpResponseData> _answer(
    HttpRequestData request,
    RequestDecoding decoding,
    ResponseMediaType type,
  ) async => switch (decoding) {
    DecodedRequest(request: final params) => await _exchange.run(
      request,
      params,
      type,
    ),
    DecodedBatch() => _errors.refusal(
      422,
      DiagnosticCode.batchingDisabled,
      'Batched requests are not enabled.',
    ),
    DecodingRefusal(:final status, :final code, :final message) =>
      _errors.refusal(status, code, message),
  };
}
```

```dart
/// The settings of `GraphQLHttpHandler`: the limits on what a client may send
/// and how results are reported (R5.5).
///
/// Every limit is checked by the handler's constructor, which throws an
/// `ArgumentError` naming the option for a value that makes no sense.
///
/// {@category http}
final class HttpOptions {
  /// Creates the options; the defaults suit a public endpoint.
  const HttpOptions({
    this.maxBodyBytes = 1048576,
    this.bodyTimeout = const Duration(seconds: 30),
    this.maxJsonDepth = 64,
    this.maxUriLength = 8192,
    this.usesPartialSuccessStatus = true,
  });

  /// The longest request body accepted, in bytes; a longer one is refused with
  /// `413` (`GQL423`), by its `content-length` before it is read or by a
  /// running count while it is.
  final int maxBodyBytes;

  /// How long the whole body may take to arrive; a slower client is refused
  /// with `408` (`GQL427`).
  final Duration bodyTimeout;

  /// The deepest nesting of arrays and objects accepted in the JSON body and
  /// in the JSON parameters of a `GET`; a deeper one is refused with `400`
  /// (`GQL424`).
  final int maxJsonDepth;

  /// The longest request URI accepted, in characters; a longer one is refused
  /// with `414` (`GQL426`) before anything else is looked at.
  final int maxUriLength;

  /// Whether a result that holds errors is sent with status `294` when the
  /// client accepts `application/graphql-response+json`, which tells a client
  /// that reads only the status that the result is partial.
  ///
  /// A client that does not accept that media type always gets `200`.
  final bool usesPartialSuccessStatus;
}
```

```dart
/// Runs one decoded request through the pipeline and writes its result as
/// JSON (spec section 4, step 9).
@internal
final class JsonExchange<C> {
  /// Creates an exchange over [server] that writes with [writer].
  const JsonExchange(this.server, this.writer);

  /// The pipeline.
  final GraphQLServer<C> server;

  /// Writes a result as an HTTP response.
  final ResultWriter writer;

  /// The operation types plain JSON can deliver: a subscription needs a
  /// stream, which only the other transports have.
  static const Set<OperationType> allowedOperationTypes = {
    OperationType.query,
    OperationType.mutation,
  };

  /// The pipeline's answer to [params], sent by [http], as a response of
  /// media type [type].
  Future<HttpResponseData> run(
    HttpRequestData http,
    GraphQLRequest params,
    ResponseMediaType type,
  ) async {
    final response = await server.handle(
      ServerRequest(
        params: params,
        info: RequestInfo(
          method: http.method,
          uri: http.uri,
          headers: http.headers,
          source: http.source,
        ),
        cancelSignal: http.cancelSignal,
        allowedOperationTypes: allowedOperationTypes,
      ),
    );
    switch (response) {
      case SingleResponse():
        return writer.single(response, type);
      case StreamResponse(:final results):
        // Only an extension can make one; nobody will listen, so release it.
        results.listen(null).cancel().ignore();
        return TransportErrors(
          server.profile.maskErrors,
        ).unexpected(StateError('A stream cannot be sent as JSON.'));
    }
  }
}
```

```dart
/// Turns the body of a `POST` into a decoding: it checks the content type and
/// the declared length, reads the body within the limits and decodes the JSON
/// (spec section 4, steps 5 to 8).
@internal
final class PostBody {
  /// Creates the reader for a handler configured with [options].
  const PostBody(this.options);

  /// The limits to apply.
  final HttpOptions options;

  /// Decodes the body of [request]; the body is not touched when the content
  /// type or the declared length already refuse the request.
  Future<RequestDecoding> decode(HttpRequestData request) async {
    if (!_isJson(ContentType.parse(request.header('content-type')))) {
      return const DecodingRefusal(
        415,
        DiagnosticCode.unsupportedMediaType,
        'A POST request must have the content type application/json.',
      );
    }
    final length = int.tryParse(request.header('content-length')?.trim() ?? '');
    if (length != null && length > options.maxBodyBytes) return _tooLarge();
    final result = await BodyReader(
      options.maxBodyBytes,
      options.bodyTimeout,
    ).read(request.body);
    return switch (result) {
      BodyBytes(:final bytes) => JsonBodyDecoder(
        maxJsonDepth: options.maxJsonDepth,
      ).decode(bytes),
      BodyTooLarge() => _tooLarge(),
      BodyTimedOut() => DecodingRefusal(
        408,
        DiagnosticCode.requestBodyTimeout,
        'The request body did not arrive within '
        '${options.bodyTimeout.inMilliseconds} ms.',
      ),
      BodyFailed() => const DecodingRefusal(
        400,
        DiagnosticCode.malformedRequestBody,
        'The request body could not be read.',
      ),
    };
  }

  // `application/json`, with no parameter but an optional utf-8 charset.
  bool _isJson(ContentType? type) =>
      type != null &&
      type.mediaType == 'application/json' &&
      type.parameters.keys.every((name) => name == 'charset') &&
      (type.charset == null || type.charset == 'utf-8');

  DecodingRefusal _tooLarge() => DecodingRefusal(
    413,
    DiagnosticCode.requestBodyTooLarge,
    'The request body is larger than ${options.maxBodyBytes} bytes.',
  );
}
```

```dart
/// How a `GraphQLHttpHandler` runs a JSON array of requests, which it refuses
/// unless `HttpOptions.batching` holds a policy (R5.12).
///
/// Batching is off by default because one HTTP request then carries many
/// operations, which defeats the per-request limits a proxy or a rate limiter
/// applies (R5.15). A host turns it on for clients that batch to save round
/// trips, such as Apollo's `BatchHttpLink`. Items run one after the other, in
/// order, each through the whole pipeline; they share one cost budget, so the
/// server's `maxCost` bounds the batch, not each item.
///
/// {@category http}
final class BatchPolicy {
  /// Creates a policy that accepts batches of at most [maxRequests] items.
  const BatchPolicy({this.maxRequests = 10, this.allowsMutations = false});

  /// The most items a batch may hold; a longer one, or an empty one, is
  /// refused with `422` (`GQL429`). Must be at least one.
  final int maxRequests;

  /// Whether an item may be a mutation; when it may not, the item's slot
  /// holds a `GQL431` error and the other items still run.
  final bool allowsMutations;
}
```

```dart
/// Runs the items of a batch and writes their results as one response (spec
/// section 6).
@internal
final class BatchRunner<C> {
  /// Creates a runner over [server] that follows [policy] and writes with
  /// [writer].
  const BatchRunner(this.server, this.policy, this.writer);

  /// The pipeline.
  final GraphQLServer<C> server;

  /// The size and operation types the batch may have.
  final BatchPolicy policy;

  /// Writes the results as an HTTP response.
  final ResultWriter writer;

  TransportErrors get _errors => TransportErrors(server.profile.maskErrors);

  Set<OperationType> get _allowedOperationTypes => {
    OperationType.query,
    if (policy.allowsMutations) OperationType.mutation,
  };

  /// The response to [items], sent by [http], in media type [type].
  ///
  /// Every item is decoded before the first runs, so a malformed one refuses
  /// the batch and nothing has been executed; then the items run in order,
  /// sharing one cost budget.
  Future<HttpResponseData> run(
    HttpRequestData http,
    List<JsonValue> items,
    ResponseMediaType type,
  ) async => switch (_decode(items)) {
    DecodeFailure(:final message) => _errors.refusal(
      422,
      DiagnosticCode.malformedRequestParameters,
      message,
    ),
    DecodeSuccess(:final value) => await _runAll(http, value, type),
  };

  Future<HttpResponseData> _runAll(
    HttpRequestData http,
    List<GraphQLRequest> requests,
    ResponseMediaType type,
  ) async {
    final budget = CostBudget();
    final payloads = <ResponsePayload>[];
    for (final params in requests) {
      payloads.add(await _runItem(http, params, budget));
    }
    return writer.batch(payloads, type);
  }

  DecodeResult<List<GraphQLRequest>> _decode(List<JsonValue> items) {
    final requests = <GraphQLRequest>[];
    for (var index = 0; index < items.length; index++) {
      switch (GraphQLRequest.decode(items[index])) {
        case DecodeSuccess(:final value):
          requests.add(value);
        case DecodeFailure() && final failure:
          return DecodeFailure(
            'The request at index $index is malformed: '
            '${const FailureDescription().of(failure)}',
          );
      }
    }
    return DecodeSuccess(requests);
  }

  Future<ResponsePayload> _runItem(
    HttpRequestData http,
    GraphQLRequest params,
    CostBudget budget,
  ) async {
    final response = await server.handle(
      const PipelineRequests().of(
        http,
        params,
        allowedOperationTypes: _allowedOperationTypes,
        costBudget: budget,
      ),
    );
    switch (response) {
      case SingleResponse(:final payload):
        return payload;
      case StreamResponse(:final results):
        // Only an extension can make one; nobody will listen, so release it.
        results.listen(null).cancel().ignore();
        return RequestErrorResult(
          errors: [
            _errors.unexpectedError(
              StateError('A stream cannot be sent in a batch.'),
            ),
          ],
        );
    }
  }
}
```

```dart
/// A body that counts the bytes pulled from it and notes when it is cancelled.
final class CountingBody {
  CountingBody(this.chunkSize, this.chunkCount);

  final int chunkSize;
  final int chunkCount;
```

+## Handling a request
+
+Build the `GraphQLServer` as usual, wrap it in a handler and call `handle`.

+## Media types and status codes
+
+`Accept` is read as media ranges with quality values. The handler offers
+`application/graphql-response+json` first and `application/json` second;
+`*/*` and `application/*` therefore give the first. A missing or blank `Accept`
+is treated as `application/json`, so a client that does not know the new media
+type keeps working; an `Accept` that allows neither is a `406`.
+
+A result of the pipeline is written in the chosen type with `charset=utf-8`.
+A refusal the transport itself makes (a size limit, a wrong content type, a bad
+batch) is always `application/json`, because it is not a well-formed
+GraphQL-over-HTTP response, and its body is
+`{"errors":[{"message":...,"extensions":{"code":"GQL4xx"}}]}`.
+
+| Result | `graphql-response+json` | `application/json` |
+|---|---|---|
+| executed, no errors | `200` | `200` |
+| executed, errors present | `294` (`200` with `usesPartialSuccessStatus: false`) | `200` |
+| the document does not parse (`GQL0xx`) | `400` | `400` |
+| CSRF prevention (`GQL403`) | `403` | `403` |
+| any other request error: no query, validation, limits, persisted documents, variables, `GQL430`, `GQL431` | `422` | `422` |
+| a `GET` mutation | `405` with `allow` | `405` with `allow` |
+| internal error | `500` | `500` |

+## Limits
+
+`HttpOptions` sets the limits; the handler's constructor throws an
+`ArgumentError` naming an option that makes no sense.
+
+| Option | Default | Effect |
+|---|---|---|
+| `maxBodyBytes` | 1 MiB | a longer body is `413` |
+| `bodyTimeout` | 30 s | the whole body must arrive within it, else `408` |
+| `maxJsonDepth` | 64 | nesting of the JSON body and of the JSON parameters of a `GET` |
+| `maxUriLength` | 8192 characters | a longer URI is `414`, before anything else |
+| `usesPartialSuccessStatus` | `true` | `294` for an executed result with errors |
+| `batching` | `null` | a `BatchPolicy` turns batching on |
+
+A `content-length` header can lie or be absent, so the handler refuses a
+declared length over the limit without reading, and otherwise counts the bytes
+that really arrive: it cancels the stream the moment the count passes the limit,
+so it never holds more than `maxBodyBytes` plus one chunk. The time limit covers
+the whole body, not each chunk, so a client that trickles one byte at a time is
+stopped too.
+
+The handler bounds only what it controls. A client that is slow to send its
+headers, or that holds a connection open and idle, is not seen by the handler
+at all: set `HttpServer.idleTimeout` and a header timeout in the host, or
+`client_header_timeout` in the proxy in front of it. The size of the headers
+is also the host's (`431`).
+
+Depth is measured before the JSON is decoded, so a body nested 100,000 levels
+deep is a quick `400` and cannot overflow the stack.

+How a batch runs:
+
+- The batch is refused whole, before anything runs, when it is empty, longer
+  than `maxRequests` (the items are not even decoded then) or when one item is
+  not a request (the message names its index).
+- Items run one after the other, in order, each through the whole pipeline
+  with its own context.
+- Items may be queries; with `allowsMutations` they may also be mutations. A
+  refused item holds `GQL431` in its slot and the others still run. A
+  subscription is never batched.

+  bounds the summed field cost and the summed type cost of the whole batch. An
+  item that alone is over `maxCost` is `GQL238`; one that would bring the sum
+  over it is `GQL430` in its slot and is not charged.
+- The response is `200` with a JSON array of the items' results in order, in
+  the negotiated media type, because one status cannot describe several
+  results.

+## Writing a host adapter
+
+An adapter for a framework does three things: convert the request, call the
+handler, write the response.
+
+```text
+Future<void> serve(FrameworkRequest request, FrameworkResponse out) async {
+  final response = await handler.handle(
+    HttpRequestData(
+      method: request.method,
+      uri: request.requestedUri,        // the full URI, query string included
+      headers: request.headers,         // repeated values joined with ", "
+      body: request.bodyStream,         // not read into memory first
+      source: request,                  // the handler never reads it
+      cancelSignal: clientGone,         // cancelled when the client leaves
+    ),
+  );
+  out.status = response.status;
+  response.headers.forEach(out.setHeader);
+  switch (response.body) {
+    case FixedBody(:final bytes):
+      out.write(bytes);
+    case StreamedBody(:final chunks):
+      // Write each chunk as it comes, flush it, and cancel the subscription
+      // when the client goes away.
+      await out.addStream(chunks);
+  }
+  await out.close();
+}
+```
+
+Pass a body stream, not a buffered list, when the framework gives one: the
+handler then never buffers more than `maxBodyBytes`. Cancel the `CancelSignal`
+when the connection closes so that a long query stops (see the Cancellation
+guide). Compare the method as the framework gives it; the handler ignores its
+case. A `StreamedBody` is an event stream: write it as it arrives, without
+buffering, and cancel the subscription when the client goes away.

+## Security notes
+
+- **CSRF prevention stays in the pipeline.** A `GET` needs a header such as
+  `graphql-require-preflight`, or `GQL403` (`403`) refuses it, as the server's
+  `CsrfPrevention` is configured (see the Server guide); a `POST` with a JSON
+  content type passes. The handler passes the pipeline the method, the URI and
+  the headers and adds nothing of its own.
+- **CORS is the host's.** Answer `OPTIONS` preflights and add
+  `access-control-*` headers in the adapter, with the origins you trust. The
+  handler answers `OPTIONS` with `405`.
+- **Batching is off** until you choose a `BatchPolicy`; keep `maxRequests` small
+  and `allowsMutations` off unless a client needs them, and set a `maxCost` in
+  the server's limits so the shared budget bounds a batch.
+- **Errors are masked** by the production profile, in transport refusals too:
+  an unexpected failure in the handler is `GQL330` with a generic message.
+- **Subscriptions are refused** over plain JSON (`GQL431`), before the context
+  is built; they have their own transports.
