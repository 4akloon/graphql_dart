**Goal:** Deliver the request policy links of `typed_graphql_client` (R8.4): `RetryLink` with `RetryPolicy` and the `Idempotent` context entry, `DedupeLink`, `PersistedQueryLink` (automatic persisted queries and trusted documents, matching the M6 server) and `AuthLink` (token header, single-flight refresh on a 401), with the Request Policies guide.

**Architecture:** A new folder `lib/src/policy/` (category `policy`, guide `doc/policies.md`). Every run turns anything a caller's callback throws into an error event, then ends its stream and cancels the upstream (spec section 10, "Stream errors").

### Task 1: feat(typed_graphql_client): add RetryLink, RetryPolicy and Idempotent

**Why.** Spec section 10. `RetryLink` sends a failed query, or a mutation marked `Idempotent()`, again after `backoff.delayFor(attempt, random)` while `RetryPolicy.isRetryable` says so (by default a network failure, a timeout, or 408, 429, 500, 502, 503, 504), up to `maxAttempts`; a subscription passes through. # Request Policies

````markdown
Request policies are middle links that make a plain transport survive the
real world: they send a request again after a failure that may pass, add
what the server needs, or save bytes. Each one forwards the request to the
rest of the chain.

## Retrying

`RetryLink(policy:, random:)` sends a request again when it got no GraphQL
response and the reason may pass. `RetryPolicy(maxAttempts: 3, backoff:,
retryIf:)` decides how often (the first attempt counts) and how long to wait
(`Backoff`, full jitter). By default it retries a `NetworkFailure`, a
`RequestTimedOut` and an `HttpStatusFailure` with status 408, 429, 500, 502,
503 or 504; `retryIf` replaces that decision. A GraphQL error is an answer
and is never retried. When the attempts run out, the last failure is
delivered.

It retries queries. A mutation is retried only when its context holds
`Idempotent()`, because a lost answer does not say whether the server applied
it; a subscription is forwarded unchanged (the WebSocket link reconnects on
its own). Cancelling the call cancels the wait and the running attempt.
The files of a request with `UploadFiles` are sent again on each attempt.
````

```dart
/// Sends a request again when it failed for a reason that may pass (R8.4).
///
/// It retries queries, and mutations whose context has [Idempotent]; a
/// subscription and any other mutation are forwarded unchanged (the
/// WebSocket link reconnects on its own). A GraphQL error is an answer and
/// is delivered. After a failure the policy accepts, the link waits for the
/// policy's backoff and forwards the same request again; the last failure is
/// delivered when the attempts run out. Cancelling the stream cancels the
/// wait and the running attempt.
///
/// The files of an `UploadFiles` entry are sent again on each attempt, since
/// every `UploadFile` reopens its content per attempt. A stream error from
/// the links below that is an [Exception] is turned into a `LinkFailure`
/// holding a `NetworkFailure`, so that the policy can judge it; any other
/// error, and an error thrown by `retryIf`, ends the stream as an error.
///
/// {@category policy}
final class RetryLink extends Link {
  /// Creates a link that follows [policy]; [random] draws the delays and
  /// defaults to a fresh [Random]. A `maxAttempts` below 1 is an
  /// [ArgumentError].
  RetryLink({this.policy = const RetryPolicy(), Random? random})
    : _random = random ?? Random() {
    if (policy.maxAttempts < 1) {
      throw ArgumentError.value(
        policy.maxAttempts,
        'policy.maxAttempts',
        'must be at least 1',
      );
    }
  }

  /// The decisions this link follows.
  final RetryPolicy policy;

  final Random _random;

  @override
  Stream<LinkResult> request(LinkRequest request, NextLink forward) {
    if (!_isRetriable(request)) {
      return forward(request);
    }
    return RetryRun(policy, _random, request, forward).results;
  }

  bool _isRetriable(LinkRequest request) => switch (request.type) {
    OperationType.query => true,
    OperationType.mutation => request.context.entry<Idempotent>() != null,
    OperationType.subscription => false,
  };
}
```

```dart
/// When and how often `RetryLink` sends a request again (R8.4).
///
/// {@category policy}
final class const RetryPolicy({
  /// How many times a request is sent in all, the first included.
  final int maxAttempts = 3,

  /// How long to wait before each retry.
  final Backoff backoff = const Backoff(),

  /// Decides whether a failure is worth another attempt; null keeps the
  /// default of [isRetryable].
  final bool Function(ClientFailure failure)? retryIf,
}) {
  /// Creates a policy.
  this;

  /// The HTTP statuses the default decision retries: the request timed
  /// out, the server is overloaded or it failed on its own side.
  static const List<int> retryableStatuses = [408, 429, 500, 502, 503, 504];

  /// Whether [failure] is worth another attempt: [retryIf] when given,
  /// else a network failure, a timeout or a status of [retryableStatuses].
  /// A GraphQL error is not a failure and is never retried.
  bool isRetryable(ClientFailure failure) {
    final decide = retryIf;
    if (decide != null) {
      return decide(failure);
    }
    return switch (failure) {
      NetworkFailure() || RequestTimedOut() => true,
      HttpStatusFailure(:final statusCode) => retryableStatuses.contains(
        statusCode,
      ),
      _ => false,
    };
  }
}
```

```dart
import 'dart:async';
import 'dart:math';

import '../client/client_failure.dart';
import '../link/link_request.dart';
import '../link/link_result.dart';
import '../link/next_link.dart';
import 'retry_policy.dart';

/// The attempts of one request for `RetryLink`: it forwards the request,
/// waits after a failure the policy accepts, and forwards it again.
final class RetryRun {
  /// Creates the run of [_request]; nothing starts before the first listener.
  RetryRun(this._policy, this._random, this._request, this._forward) {
    _controller.onListen = _attempt;
    _controller.onCancel = _stop;
  }

  final RetryPolicy _policy;
  final Random _random;
  final LinkRequest _request;
  final NextLink _forward;
  final StreamController<LinkResult> _controller =
      StreamController<LinkResult>();

  StreamSubscription<LinkResult>? _subscription;
  Timer? _timer;
  int _attemptCount = 0;

  /// What the caller listens to: the delivered results.
  Stream<LinkResult> get results => _controller.stream;

  void _attempt() {
    _attemptCount++;
    _subscription = _forward(
      _request,
    ).listen(_onResult, onError: _onError, onDone: _finish);
  }

  void _onResult(LinkResult result) {
    if (result case LinkFailure(:final failure)) {
      final bool isRetried;
      try {
        isRetried = _willRetry(failure);
      } on Object catch (error, stackTrace) {
        // The caller's `retryIf` threw: deliver it, or the stream would hang.
        _abort(error, stackTrace);
        return;
      }
      if (isRetried) {
        _wait();
        return;
      }
    }
    _controller.add(result);
  }

  void _abort(Object error, StackTrace stackTrace) {
    unawaited(_subscription?.cancel());
    _subscription = null;
    _controller.addError(error, stackTrace);
    unawaited(_controller.close());
  }

  // A link must not fail its stream (spec section 6); an Exception that
  // does arrive is a network failure, an Error is a bug and passes on.
  void _onError(Object error, StackTrace stackTrace) {
    if (error is Exception) {
      _onResult(LinkFailure(NetworkFailure(error)));
    } else {
      _controller.addError(error, stackTrace);
    }
  }

  bool _willRetry(ClientFailure failure) =>
      _attemptCount < _policy.maxAttempts && _policy.isRetryable(failure);

  /// Drops the failed attempt and forwards the request after the delay of
  /// the retry that is about to start (the first retry is number 0).
  void _wait() {
    unawaited(_subscription?.cancel());
    _subscription = null;
    final delay = _policy.backoff.delayFor(_attemptCount - 1, _random);
    _timer = Timer(delay, () {
      _timer = null;
      _attempt();
    });
  }

  void _finish() {
    _subscription = null;
    unawaited(_controller.close());
  }

  Future<void> _stop() {
    _timer?.cancel();
    _timer = null;
    final cancelled = _subscription?.cancel();
    _subscription = null;
    return cancelled ?? Future<void>.value();
  }
}
```

```dart
/// Lets identical queries that are in flight at the same time share one
/// forwarded request (R8.4).
///
/// Two queries are identical when their bodies (document, variables and
/// extensions, compared as JSON values) and their [RequestHeaders] are equal.
/// Each caller gets the shared result through its own stream. A caller that
/// cancels leaves the others their result; the forwarded request is cancelled
/// when the last caller cancels. The sharing ends at the first result, so a
/// query sent later goes out again: this link is not a cache (the normalized
/// cache arrives with M12).
///
/// The bodies are compared as `JsonObject`s, which ignore the order of keys:
/// variables written in another order are still identical. A stream error from
/// the links below reaches every caller untouched, and a forward that throws
/// is the error of the callers that joined.
///
/// Mutations, subscriptions and requests with `UploadFiles` pass through.
///
/// {@category policy}
final class DedupeLink extends Link {
  /// Creates a link with nothing in flight.
  DedupeLink();

  final Map<JsonValue, SharedRequest> _inFlight = {};

  @override
  Stream<LinkResult> request(LinkRequest request, NextLink forward) {
    if (!_isShareable(request)) {
      return forward(request);
    }
    final key = _keyOf(request);
    // The entry is found when the caller listens, not when it asks, so a
    // caller that listens late still joins a request that is in flight.
    return Stream<LinkResult>.multi((caller) {
      final shared = _inFlight[key] ??= SharedRequest(
        request,
        forward,
        () => _inFlight.remove(key),
      );
      shared.join(caller);
    });
  }

  bool _isShareable(LinkRequest request) =>
      request.type == OperationType.query &&
      request.context.entry<UploadFiles>() == null;

  JsonValue _keyOf(LinkRequest request) {
    final headers = request.context.entry<RequestHeaders>()?.values ?? const {};
    return JsonArray([
      request.body.toJson(),
      JsonObject({
        for (final MapEntry(:key, :value) in headers.entries)
          key: JsonString(value),
      }),
    ]);
  }
}
```

```dart
/// One forwarded request and the callers of `DedupeLink` waiting for its
/// answer.
final class SharedRequest {
  /// Creates the request to forward when the first caller joins;
  /// [_onEnded] removes it from the link's table, once.
  SharedRequest(this._request, this._forward, this._onEnded);

  final LinkRequest _request;
  final NextLink _forward;
  final void Function() _onEnded;
  final List<MultiStreamController<LinkResult>> _callers = [];
  StreamSubscription<LinkResult>? _upstream;
  bool _isListed = true;
  bool _isStarted = false;
  bool _isEnded = false;

  /// Adds [caller] to those waiting; the first one starts the request. A
  /// forward that throws is the error of every caller, and the request is
  /// no longer shared.
  void join(MultiStreamController<LinkResult> caller) {
    _callers.add(caller);
    caller.onCancel = () => _leave(caller);
    if (_isStarted) {
      return;
    }
    _isStarted = true;
    final Stream<LinkResult> results;
    try {
      results = _forward(_request);
    } on Object catch (error, stackTrace) {
      _onError(error, stackTrace);
      _onDone();
      return;
    }
    _upstream = results.listen(
      _onResult,
      onError: _onError,
      onDone: _onDone,
    );
    // A source that ends inside `listen` has already run `_onDone`, which
    // could not clear the field before this assignment.
    if (_isEnded) {
      _upstream = null;
    }
  }

  void _onResult(LinkResult result) {
    _unlist();
    for (final caller in List.of(_callers)) {
      caller.add(result);
    }
  }

  void _onError(Object error, StackTrace stackTrace) {
    _unlist();
    for (final caller in List.of(_callers)) {
      caller.addError(error, stackTrace);
    }
  }

  void _onDone() {
    _isEnded = true;
    _unlist();
    for (final caller in List.of(_callers)) {
      unawaited(caller.close());
    }
    _callers.clear();
    _upstream = null;
  }

  Future<void>? _leave(MultiStreamController<LinkResult> caller) {
    _callers.remove(caller);
    if (_callers.isNotEmpty) {
      return null;
    }
    _unlist();
    final cancelled = _upstream?.cancel();
    _upstream = null;
    return cancelled;
  }

  void _unlist() {
    if (_isListed) {
      _isListed = false;
      _onEnded();
    }
  }
}
```

```dart
import 'package:typed_graphql/typed_graphql.dart';

import '../link/link_result.dart';

/// Reads the two answers of a server that stores persisted queries: "I do
/// not know this hash" and "I do not store queries" (M6 section 11).
///
/// A server says either with a message (the Apollo convention) or with an
/// `extensions.code`: `GQL410` and `GQL412` for this repository's server.
final class const PersistedQueryErrors() {
  /// Creates the reader.
  this;

  /// Whether [result] says the hash is unknown, so the text must follow.
  bool isNotFound(LinkResult result) => _says(
    result,
    'PersistedQueryNotFound',
    const {'GQL410', 'PERSISTED_QUERY_NOT_FOUND'},
  );

  /// Whether [result] says the server stores no queries, so the text must
  /// be sent every time.
  bool isNotSupported(LinkResult result) => _says(
    result,
    'PersistedQueryNotSupported',
    const {'GQL412', 'PERSISTED_QUERY_NOT_SUPPORTED'},
  );

  bool _says(LinkResult result, String message, Set<String> codes) {
    if (result is! LinkPayload) {
      return false;
    }
    return result.payload.errors.any(
      (error) =>
          error.message == message ||
          switch (error.extensions?['code']) {
            JsonString(:final value) => codes.contains(value),
            _ => false,
          },
    );
  }
}
```

```dart
/// sent is an answer and is delivered, not answered again. A stream error
/// from the links below reaches the caller untouched.
///
/// {@category policy}
final class PersistedQueryLink extends Link {
  /// Creates a link in the automatic mode, or in the trusted mode when
  /// [isAutomatic] is false.
  PersistedQueryLink({this.isAutomatic = true});

  /// Whether the link falls back to the text when the server does not know
  /// the hash.
  final bool isAutomatic;

  bool _isSupportedByServer = true;

  @override
  Stream<LinkResult> request(LinkRequest request, NextLink forward) {
    if (!_isSupportedByServer || !_isApplicable(request)) {
      return forward(request);
    }
    return PersistedQueryRun(
      request,
      forward,
      isAutomatic: isAutomatic,
      onNotSupported: () => _isSupportedByServer = false,
    ).results;
  }

  bool _isApplicable(LinkRequest request) =>
      request.type != OperationType.subscription &&
      request.context.entry<UploadFiles>() == null;
}
```

```dart
import 'package:typed_graphql/typed_graphql.dart';

import '../link/link_request.dart';
import '../link/link_result.dart';
import '../link/next_link.dart';
import 'persisted_query_errors.dart';

/// The attempts of one request for `PersistedQueryLink`: the hash alone,
/// then, when the server asks for it, the text.
final class PersistedQueryRun {
  /// Creates the run of [_request]; nothing starts before the first
  /// listener. [onNotSupported] tells the link to stop sending hashes.
  PersistedQueryRun(
    this._request,
    this._forward, {
    required this.isAutomatic,
    required this.onNotSupported,
  }) {
    _controller.onListen = _sendHashAlone;
    _controller.onCancel = _stop;
  }

  final LinkRequest _request;
  final NextLink _forward;

  /// Whether a miss is answered with the text; false for trusted documents.
  final bool isAutomatic;

  /// Called when the server says it stores no queries.
  final void Function() onNotSupported;
  final PersistedQueryErrors _errors = const PersistedQueryErrors();
  final StreamController<LinkResult> _controller =
      StreamController<LinkResult>();

  StreamSubscription<LinkResult>? _subscription;

  /// What the caller listens to: the answers of the attempt that was kept.
  Stream<LinkResult> get results => _controller.stream;

  void _sendHashAlone() => _listenTo(
    _withHash().withDocumentText(sendsDocumentText: false),
    onResult: _onFirstResult,
  );

  void _listenTo(
    LinkRequest request, {
    required void Function(LinkResult result) onResult,
  }) {
    _subscription = _forward(request).listen(
      onResult,
      onError: _controller.addError,
      onDone: () {
        _subscription = null;
        unawaited(_controller.close());
      },
    );
  }

  void _onFirstResult(LinkResult result) {
    if (isAutomatic && _errors.isNotFound(result)) {
      _resend(_withHash());
    } else if (isAutomatic && _errors.isNotSupported(result)) {
      onNotSupported();
      _resend(_request);
    } else {
      _controller.add(result);
    }
  }

  /// Drops the hash-only attempt and sends [request], whose answer is the
  /// one delivered.
  void _resend(LinkRequest request) {
    unawaited(_subscription?.cancel());
    _subscription = null;
    _listenTo(request, onResult: _controller.add);
  }

  /// The request with `extensions.persistedQuery` added to its extensions.
  LinkRequest _withHash() => _request.withExtensions(
    JsonObject({
      ...?_request.extensions?.fields,
      'persistedQuery': JsonObject({
        'version': JsonNumber(1),
        'sha256Hash': JsonString(_request.document.sha256),
      }),
    }),
  );

  Future<void> _stop() {
    final cancelled = _subscription?.cancel();
    _subscription = null;
    return cancelled ?? Future<void>.value();
  }
}
```

+## Authentication
+
+`AuthLink(token:, refresh:, headerName:, scheme:, isUnauthorized:)` adds the
+header `authorization: Bearer <token>` to each request. `token` gives the
+token (a `String?`, possibly from a `Future`; null sends no header);
+`headerName` and `scheme` change the header, and an empty `scheme` sends the
+bare token. The header joins the request's `RequestHeaders`.
+
+When the answer is a 401, an `HttpStatusFailure` with status 401 or a payload
+whose `HttpResponseInfo` says 401 (`isUnauthorized` replaces that test), and
+`refresh` was given, the link asks `token` once more. A token that changed
+meanwhile, because another request already renewed it, is sent as it is.
+Otherwise `refresh` runs, once for all the requests that wait for it at the
+same time, and the request is sent again with the token it gives. A request is
+sent again at most once, so a second 401 is the answer, and so is the first
+when `refresh` is missing or gives null. A mutation can be sent again safely:
+a 401 refuses the request before the server runs it.

+`AuthenticationFailure`; the request is not sent again.

```dart
///
/// Before forwarding, the link calls [token] and, when it gives a string,
/// adds the header `<headerName>: <scheme> <token>` to the request's
/// `RequestHeaders` (just the token when [scheme] is empty); a null token adds
/// nothing. When the answer is a 401 (the default [isUnauthorized]: an
/// `HttpStatusFailure` with status 401, or a payload whose `HttpResponseInfo`
/// has it) and a [refresh] callback was given, the link asks [token] again: a
/// new token, such as one a concurrent request stored, is sent as it is;
/// otherwise [refresh] runs, once for every request that waits for it at the
/// same time, and the request is sent again with its result. A request is
/// sent again at most once; a refresh that is missing or gives null leaves the
/// 401 as the answer. An [Exception] thrown by [token] or [refresh] is a
/// `LinkFailure` holding an `AuthenticationFailure`, and the request is not
/// forwarded again; an error that is not an [Exception], and anything thrown
/// by [isUnauthorized], ends the stream as an error. A stream error from the
/// links below reaches the caller untouched.
///
/// {@category policy}
final class AuthLink extends Link {
  /// Creates a link that reads the token with [token]; [refresh] renews it.
  AuthLink({
    required this.token,
    this.refresh,
    this.headerName = 'authorization',
    this.scheme = 'Bearer',
    bool Function(LinkResult result)? isUnauthorized,
  }) : isUnauthorized = isUnauthorized ?? _isHttpUnauthorized,
       _renewal = TokenRenewal(token, refresh);

  /// Gives the token to send, or null to send none.
  final FutureOr<String?> Function() token;

  /// Fetches a new token after a 401, or null when the token cannot be
  /// renewed.
  final Future<String?> Function()? refresh;

  /// The header that carries the token.
  final String headerName;

  /// The word before the token in the header; empty for none.
  final String scheme;

  /// Whether a result says the server refused the token.
  final bool Function(LinkResult result) isUnauthorized;

  final TokenRenewal _renewal;

  @override
  Stream<LinkResult> request(LinkRequest request, NextLink forward) => AuthRun(
    request,
    forward,
    renewal: _renewal,
    authorize: _authorize,
    isUnauthorized: isUnauthorized,
  ).results;

  LinkRequest _authorize(LinkRequest request, String? token) {
    if (token == null) {
      return request;
    }
    final value = scheme.isEmpty ? token : '$scheme $token';
    final headers = request.context.entry<RequestHeaders>();
    return request.withContext(
      request.context.withEntry(
        (headers ?? RequestHeaders(const {})).withHeader(headerName, value),
      ),
    );
  }

  static bool _isHttpUnauthorized(LinkResult result) => switch (result) {
    LinkFailure(failure: HttpStatusFailure(statusCode: 401)) => true,
    LinkPayload(:final context) =>
      context.entry<HttpResponseInfo>()?.statusCode == 401,
    _ => false,
  };
}
```

```dart
import 'dart:async';

import '../client/client_failure.dart';
import '../link/link_request.dart';
import '../link/link_result.dart';
import '../link/next_link.dart';
import 'token_renewal.dart';

/// The attempts of one request for `AuthLink`: the request with the token,
/// and once more with a renewed token when the first answer is a 401.
final class AuthRun {
  /// Creates the run of [request]; nothing starts before the first listener.
  /// [authorize] gives the request with a token's header.
  AuthRun(
    this.request,
    this.forward, {
    required this.renewal,
    required this.authorize,
    required this.isUnauthorized,
  }) {
    _controller.onListen = _begin;
    _controller.onCancel = _stop;
  }

  /// The request as the caller made it.
  final LinkRequest request;

  /// Sends a request to the rest of the chain.
  final NextLink forward;

  /// Reads and renews the token.
  final TokenRenewal renewal;

  /// The request with the header of a token (null: no header).
  final LinkRequest Function(LinkRequest request, String? token) authorize;

  /// Whether a result says the token was refused.
  final bool Function(LinkResult result) isUnauthorized;

  final StreamController<LinkResult> _controller =
      StreamController<LinkResult>();
  StreamSubscription<LinkResult>? _subscription;
  bool _isCancelled = false;

  /// What the caller listens to: the answer of the attempt that was kept.
  Stream<LinkResult> get results => _controller.stream;

  Future<void> _begin() async {
    final String? token;
    try {
      token = await renewal.current();
    } on Exception catch (exception) {
      _fail(exception);
      return;
    } on Object catch (error, stackTrace) {
      _abort(error, stackTrace);
      return;
    }
    _send(token, isRetry: false);
  }

  void _send(String? token, {required bool isRetry}) {
    if (_isCancelled) {
      return;
    }
    _subscription = forward(authorize(request, token)).listen(
      (result) => _onResult(result, token, isRetry: isRetry),
      onError: _controller.addError,
      onDone: () {
        _subscription = null;
        unawaited(_controller.close());
      },
    );
  }

  void _onResult(
    LinkResult result,
    String? sentToken, {
    required bool isRetry,
  }) {
    final bool isRefused;
    try {
      isRefused = !isRetry && renewal.canRefresh && isUnauthorized(result);
    } on Object catch (error, stackTrace) {
      // The caller's `isUnauthorized` threw: deliver it, or the stream hangs.
      _abort(error, stackTrace);
      return;
    }
    if (isRefused) {
      unawaited(_renew(result, sentToken));
    } else {
      _controller.add(result);
    }
  }

  /// Drops the refused attempt and sends the request again with a renewed
  /// token; with none, [refused] is the answer.
  Future<void> _renew(LinkResult refused, String? sentToken) async {
    unawaited(_subscription?.cancel());
    _subscription = null;
    final String? token;
    try {
      token = await renewal.renewed(sentToken);
    } on Exception catch (exception) {
      _fail(exception);
      return;
    } on Object catch (error, stackTrace) {
      _abort(error, stackTrace);
      return;
    }
    if (token == null) {
      _deliverAndEnd(refused);
    } else {
      _send(token, isRetry: true);
    }
  }

  void _fail(Exception exception) =>
      _deliverAndEnd(LinkFailure(AuthenticationFailure(exception)));

  /// Ends the run with a stream error and cancels the running attempt; for
  /// what is not an [Exception], which is a bug and must not be hidden.
  void _abort(Object error, StackTrace stackTrace) {
    if (_isCancelled) {
      return;
    }
    unawaited(_subscription?.cancel());
    _subscription = null;
    _controller.addError(error, stackTrace);
    unawaited(_controller.close());
  }

  void _deliverAndEnd(LinkResult result) {
    if (_isCancelled) {
      return;
    }
    _controller.add(result);
    unawaited(_controller.close());
  }

  Future<void> _stop() {
    _isCancelled = true;
    final cancelled = _subscription?.cancel();
    _subscription = null;
    return cancelled ?? Future<void>.value();
  }
}
```

```dart
import 'dart:async';

/// Reads the current token and renews it for `AuthLink`, with one refresh
/// in flight at a time.
final class TokenRenewal {
  /// Creates the renewal over the caller's [_token] and [_refresh].
  TokenRenewal(this._token, this._refresh);

  final FutureOr<String?> Function() _token;
  final Future<String?> Function()? _refresh;
  Future<String?>? _refreshing;
  int _refreshCount = 0;
  String? _lastRefreshed;

  /// Whether a refresh callback was given.
  bool get canRefresh => _refresh != null;

  /// The token to send now, or null for none.
  Future<String?> current() async => _token();

  /// The token to send again after [sentToken] was refused: the result of a
  /// refresh that is running or that finished while this call read the
  /// token, else the current token when it is another non-null one (someone
  /// else renewed it), else the result of a new refresh, which every caller
  /// waiting at the same time shares. Null when there is nothing better to
  /// send.
  Future<String?> renewed(String? sentToken) async {
    final inFlight = _refreshing;
    if (inFlight != null) {
      return inFlight;
    }
    // A slow read may return a token from before a refresh that finished
    // meanwhile; the count tells that a refresh happened since this call began.
    final countAtStart = _refreshCount;
    final latest = await current();
    final startedMeanwhile = _refreshing;
    if (startedMeanwhile != null) {
      return startedMeanwhile;
    }
    final refreshed = _lastRefreshed;
    if (_refreshCount != countAtStart && refreshed != null) {
      return refreshed;
    }
    if (latest != null && latest != sentToken) {
      return latest;
    }
    return _refreshOnce();
  }

  Future<String?> _refreshOnce() {
    final refresh = _refresh;
    if (refresh == null) {
      return Future<String?>.value();
    }
    _refreshCount++;
    return _refreshing ??= refresh().then(_remember).whenComplete(() {
      _refreshing = null;
    });
  }

  String? _remember(String? token) {
    if (token != null) {
      _lastRefreshed = token;
    }
    return token;
  }
}
```

+## The order of a chain
+
+The policies are middle links, so their order in `Link.from` matters. The
+recommended order, from the client toward the transport:
+
+1. `DedupeLink` first, so that identical queries share everything below it,
+   the retries included.
+2. `RetryLink` next, so that every attempt passes through the links below it
+   again and gets a current token.
+3. `AuthLink`, so that the header is added whatever the transport sends, and
+   so that a 401 that comes back through the persisted query link is seen.
+4. `PersistedQueryLink` last of the policies, because it decides what goes on
+   the wire (the hash or the text) and its second request is part of one
+   attempt, not a retry.
+5. Then a `SplitLink` whose branches are the terminating links of your
+   transports, one for subscriptions and one for the rest.
+

+lost to the network, the second asks for a document the server does not know,
+the third is refused for its token, and the fourth succeeds. The `MockLink`
+shows what reached the transport.

## Review Focus

- A mutation is retried only with `Idempotent()`; a subscription never; GraphQL errors never.
- Cancelling during a backoff cancels the timer; the last failure is delivered when attempts run out; `maxAttempts` below 1 is an `ArgumentError`.
- Stream errors: `RetryLink` turns an upstream `Exception` into `NetworkFailure`; the others pass errors through; a throwing callback (`retryIf`, `isUnauthorized`, a non-`Exception` from `token`/`refresh`) is an error event, then done, the upstream cancelled; nothing escapes as an uncaught error.
- `DedupeLink`: the key is the body plus `RequestHeaders`; the entry leaves the map at the first result, at the end, when `forward` throws and when the source ends inside `listen`; the forwarded request is cancelled only when the last caller cancels.
- `PersistedQueryLink`: the hash is M10's `sha256` of the minified text; a "not found" is resent once with the text; "not supported" switches to text for good; trusted mode never sends text.
- `AuthLink`: one refresh for every concurrent 401 (`TokenRenewal` order: in flight, finished meanwhile, another current token, new refresh); one resend; a null refresh delivers the 401.
