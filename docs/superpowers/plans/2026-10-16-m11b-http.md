Create `packages/typed_graphql_client/doc/http.md`:

````markdown
# HTTP

The client sends queries and mutations over GraphQL over HTTP. The link
does not depend on one HTTP library: it hands each request to an
`HttpTransport`, a one-method interface.

## Transports

`PackageHttpTransport` adapts any `http.Client` of `package:http`, so the
same client code runs on the VM, in Flutter and in a browser:

```text
import 'package:http/http.dart' as http;

final transport = PackageHttpTransport(http.Client());
```

The client you pass belongs to you: close it when the app no longer needs
it. On the browser, `http.Client()` is the fetch-based `BrowserClient`; a
Flutter app may pass `cupertino_http` or `cronet_http` instead.

A transport of your own implements `send`: it takes a `TransportRequest`
(method, URL, headers in lower case, a body stream, its length when known
and an `abortTrigger`) and returns a `TransportResponse` (status, headers,
body stream). It reports a lost connection by throwing an `Exception`, and
closes the connection when `abortTrigger` completes. Tests and in-memory
servers implement it directly.
````

```dart
import 'transport_request.dart';
import 'transport_response.dart';

/// The seam between the HTTP links and an HTTP library: sends one request
/// and returns the answer's status, headers and body stream (spec section
/// 9, R8.4).
///
/// `PackageHttpTransport` adapts any `http.Client`; tests and in-memory
/// servers implement this interface directly. A transport reports a
/// connection problem by throwing an `Exception`, from [send] or from the
/// body stream, and stops the request when its `abortTrigger` completes.
///
/// {@category http}
abstract interface class HttpTransport {
  /// Sends [request] and completes with the answer once its headers have
  /// arrived; the body is read from the answer's stream.
  Future<TransportResponse> send(TransportRequest request);
}
```

Create `packages/typed_graphql_client/lib/src/http/package_http_transport.dart`:

```dart
import 'dart:async';

import 'package:http/http.dart' as http;

import 'http_transport.dart';
import 'transport_request.dart';
import 'transport_response.dart';

/// An [HttpTransport] over any `http.Client` of `package:http`: `IOClient`,
/// the browser's `BrowserClient`, `cupertino_http`, `cronet_http` and the
/// others (R8.4).
///
/// It sends an `http.AbortableStreamedRequest`, so completing a request's
/// `abortTrigger` closes the connection on every client that supports
/// aborting. The caller owns [client] and closes it.
///
/// {@category http}
final class PackageHttpTransport(
  /// The client that sends the requests.
  final http.Client client,
) implements HttpTransport {
  /// Creates a transport over [client].
  this;

  @override
  Future<TransportResponse> send(TransportRequest request) async {
    final outgoing =
        http.AbortableStreamedRequest(
            request.method,
            request.uri,
            abortTrigger: request.abortTrigger,
          )
          ..headers.addAll(request.headers)
          ..contentLength = request.contentLength;
    final sink = outgoing.sink;
    final body = request.body;
    unawaited(
      body == null
          ? sink.close()
          : sink.addStream(body).whenComplete(sink.close),
    );
    final response = await client.send(outgoing);
    return TransportResponse(
      statusCode: response.statusCode,
      headers: response.headers,
      body: response.stream,
    );
  }
}
```

```dart
/// One HTTP request as the HTTP links hand it to an `HttpTransport`.
///
/// {@category http}
final class TransportRequest({
  /// The HTTP method, `GET` or `POST`.
  required final String method,

  /// The URL, with the query parameters of a `GET` request.
  required final Uri uri,
  Map<String, String> headers = const {},

  /// The body, read once; null for a request without one.
  final Stream<List<int>>? body,

  /// The body's length in bytes, when it is known before sending.
  final int? contentLength,

  /// Completes when the link no longer wants the answer: the transport
  /// should then close the connection.
  final Future<void>? abortTrigger,
}) {
  /// Creates a request; [headers] is copied with its names in lower case.
  this;

  /// The headers, names in lower case.
  final Map<String, String> headers = Map.unmodifiable({
    for (final MapEntry(:key, :value) in headers.entries)
      key.toLowerCase(): value,
  });

  @override
  String toString() => 'TransportRequest($method $uri)';
}
```

```dart
import 'package:meta/meta.dart';

/// The parts of a `Content-Type` header the HTTP links decide on: the
/// media type before `;` and its `charset` parameter, both in lower case.
@internal
final class MediaType {
  /// Reads [header]; a missing header has no [essence].
  factory MediaType.parse(String? header) {
    if (header == null || header.trim().isEmpty) {
      return const MediaType._(null, null);
    }
    final parts = header.split(';');
    String? charset;
    for (final parameter in parts.skip(1)) {
      final separator = parameter.indexOf('=');
      if (separator < 0) continue;
      if (parameter.substring(0, separator).trim().toLowerCase() == 'charset') {
        charset = _unquoted(parameter.substring(separator + 1).trim());
      }
    }
    return MediaType._(parts.first.trim().toLowerCase(), charset);
  }

  const MediaType._(this.essence, this.charset);

  /// The media type of a GraphQL response, GraphQL over HTTP's own.
  static const String graphQLResponse = 'application/graphql-response+json';

  /// The legacy media type of a GraphQL response.
  static const String json = 'application/json';

  /// The media type of a server-sent event stream.
  static const String eventStream = 'text/event-stream';

  /// The type and subtype, such as `application/json`; null when the
  /// header is missing.
  final String? essence;

  /// The `charset` parameter, lower-cased and unquoted; null when absent.
  final String? charset;

  /// Whether the body is UTF-8: no charset, or `utf-8`.
  bool get isUtf8 => charset == null || charset == 'utf-8';

  static String _unquoted(String value) {
    final text =
        value.length >= 2 && value.startsWith('"') && value.endsWith('"')
        ? value.substring(1, value.length - 1)
        : value;
    return text.toLowerCase();
  }

  @override
  String toString() => essence ?? '(none)';
}
```

```dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

import '../client/client_failure.dart';
import '../link/http_response_info.dart';
import '../link/link_context.dart';
import '../link/link_result.dart';
import 'media_type.dart';
import 'transport_response.dart';

/// Turns an HTTP answer into a [LinkResult]: the GraphQL over HTTP rules
/// for status codes and media types, a byte limit counted while the body
/// streams, strict UTF-8, bounded JSON nesting (spec section 9, R0.3).
///
/// It never throws for a hostile answer; an `Exception` of the body stream
/// goes to the caller, which reports it as a network failure.
@internal
final class const ResponseReader({
  /// The most bytes a body may have.
  required final int maxBytes,

  /// The deepest JSON nesting a body may have.
  required final int maxDepth,
}) {
  /// Creates a reader.
  this;

  /// Reads [response]: a payload with an `HttpResponseInfo` in its
  /// context, or the failure that explains why there is none.
  Future<LinkResult> read(TransportResponse response) async {
    final type = MediaType.parse(response.headers['content-type']);
    if (_refusal(response, type) case final failure?) {
      return LinkFailure(failure);
    }
    final bytes = await _collect(response.body);
    if (bytes == null) {
      return LinkFailure(
        ResponseFormatFailure(
          .responseTooLarge,
          'The response is longer than $maxBytes bytes.',
        ),
      );
    }
    final String text;
    try {
      text = utf8.decode(bytes);
    } on FormatException {
      return LinkFailure(
        ResponseFormatFailure(.malformedResponse, 'The response is not UTF-8.'),
      );
    }
    final info = HttpResponseInfo(
      response.statusCode,
      headers: response.headers,
    );
    return resultOf(text, LinkContext([info]));
  }

  /// The payload [text] holds, with [context], or the `GQL464` failure
  /// that says where it is malformed.
  LinkResult resultOf(String text, LinkContext context) {
    final decoded = switch (JsonReader(maxDepth: maxDepth).parse(text)) {
      DecodeSuccess(:final value) => ResponsePayload.decode(value),
      final DecodeFailure failure => failure,
    };
    return switch (decoded) {
      DecodeSuccess(:final value) => LinkPayload(value, context: context),
      final DecodeFailure failure => LinkFailure(
        ResponseFormatFailure(
          .malformedResponse,
          'The response is not a GraphQL response: $failure',
          path: failure.path,
        ),
      ),
    };
  }

  /// Why [response] is not read, or null to read it: a GraphQL response
  /// is read whatever its status, JSON only with a 2xx status.
  ClientFailure? _refusal(TransportResponse response, MediaType type) {
    final status = response.statusCode;
    final isSuccess = status >= 200 && status < 300;
    final isReadable =
        type.essence == MediaType.graphQLResponse ||
        (type.essence == MediaType.json && isSuccess);
    if (!isReadable) {
      return isSuccess
          ? ResponseFormatFailure(.unsupportedResponseType, _typeMessage(type))
          : HttpStatusFailure(status, headers: response.headers);
    }
    if (!type.isUtf8) {
      return ResponseFormatFailure(
        .unsupportedResponseType,
        'The response is in charset "${type.charset}"; only UTF-8 is read.',
      );
    }
    return null;
  }

  String _typeMessage(MediaType type) => switch (type.essence) {
    null => 'The response has no content type.',
    final essence =>
      'The response has content type "$essence", which is not a GraphQL '
          'response.',
  };

  /// The body's bytes, or null as soon as they pass [maxBytes]; leaving
  /// the loop cancels the body stream.
  Future<Uint8List?> _collect(Stream<List<int>> body) async {
    final bytes = BytesBuilder(copy: false);
    await for (final chunk in body) {
      if (bytes.length + chunk.length > maxBytes) {
        return null;
      }
      bytes.add(chunk);
    }
    return bytes.takeBytes();
  }
}
```

```dart
    String body, {
    int status = 200,
    String contentType = 'application/graphql-response+json',
  }) => answerWith(
    (request) async => TransportResponse(
      statusCode: status,
      headers: {'content-type': contentType},
      body: Stream.value(utf8.encode(body)),
    ),
  );

  /// Queues an answer computed from the request.
  void answerWith(
    Future<TransportResponse> Function(TransportRequest request) answer,
  ) => _answers.add(answer);

  /// Queues an answer that never comes: the request fails with
  /// [TransportAborted] once its abort trigger completes.
  void hang() => answerWith((request) {
    final answer = Completer<TransportResponse>();
    unawaited(
      request.abortTrigger?.then(
        (_) => answer.completeError(const TransportAborted()),
      ),
    );
    return answer.future;
  });

  @override
  Future<TransportResponse> send(TransportRequest request) async {
    requests.add(request);
    final bytes = await (request.body ?? const Stream<List<int>>.empty())
        .expand((chunk) => chunk)
        .toList();
    bodies.add(utf8.decode(bytes, allowMalformed: true));
    if (_answers.isEmpty) {
      throw StateError('FakeTransport has no answer for ${request.uri}.');
    }
    return _answers.removeAt(0)(request);
  }
}

  /// Creates the exception.
  const TransportAborted();

  @override
  String toString() => 'TransportAborted';
}
```

+## Reading the answer
+
+The link reads the answer by the GraphQL over HTTP rules:
+
+| Content type | Status | Result |
+|---|---|---|
+| `application/graphql-response+json` | any | the GraphQL response |
+| `application/json` | 2xx | the GraphQL response |
+| `application/json` | other | `HttpStatusFailure` (`GQL461`) |
+| another or none | other than 2xx | `HttpStatusFailure` (`GQL461`) |
+| another or none | 2xx | `ResponseFormatFailure` (`GQL462`) |

+arrives: past `maxResponseBytes` (16 MiB by default) the link aborts the
+request with `GQL463`. Bytes that are not UTF-8, text that is not JSON,

+is not a GraphQL response are `GQL464`, with the path of the bad value.
+The response's context holds an `HttpResponseInfo` with the status and
+headers.

+finished in time is aborted with `RequestTimedOut` (`GQL467`). Cancelling
+the call aborts the request through the transport's `abortTrigger`.

```dart
import 'dart:async';

import 'package:meta/meta.dart';

import '../client/client_failure.dart';
import '../link/link_result.dart';
import 'http_transport.dart';
import 'response_reader.dart';
import 'transport_request.dart';

/// Runs HTTP requests that have one answer each: sends, reads, applies the
/// timeout and aborts the request when its stream is cancelled (spec
/// section 9).
@internal
final class HttpExchange({
  /// Sends the requests.
  required final HttpTransport transport,

  /// Reads the answers.
  required final ResponseReader reader,

  /// How long one request may take, from sending to the end of the body;
  /// null for no limit.
  final Duration? timeout,
}) {
  /// Creates an exchange.
  this;

  /// The one result of the request [encode] writes, sent when the stream
  /// is listened to; [encode] gets the request's abort trigger.
  Stream<LinkResult> run(
    TransportRequest Function(Future<void> abortTrigger) encode,
  ) {
    final abort = Completer<void>();
    final controller = StreamController<LinkResult>(
      onCancel: () => _release(abort),
    );
    controller.onListen = () => unawaited(
      _attempt(encode, abort).then(
        (result) {
          _release(abort);
          controller.add(result);
          return controller.close();
        },
        onError: (Object error, StackTrace stackTrace) {
          _release(abort);
          controller.addError(error, stackTrace);
          return controller.close();
        },
      ),
    );
    return controller.stream;
  }

  Future<LinkResult> _attempt(
    TransportRequest Function(Future<void> abortTrigger) encode,
    Completer<void> abort,
  ) async {
    final exchange = _exchange(encode(abort.future));
    final limit = timeout;
    if (limit == null) {
      return exchange;
    }
    final timedOut = Completer<LinkResult>();
    final timer = Timer(limit, () {
      _release(abort);
      timedOut.complete(LinkFailure(RequestTimedOut(limit)));
    });
    try {
      return await Future.any([exchange, timedOut.future]);
    } finally {
      timer.cancel();
    }
  }

  Future<LinkResult> _exchange(TransportRequest request) async {
    try {
      return await reader.read(await transport.send(request));
    } on Exception catch (error) {
      return LinkFailure(NetworkFailure(error));
    }
  }

  /// Tells the transport the answer is no longer read; harmless once the
  /// body has ended.
  void _release(Completer<void> abort) {
    if (!abort.isCompleted) {
      abort.complete();
    }
  }
}
```

```dart
/// Every request is a `POST` with a JSON body and asks for
/// `application/graphql-response+json`. The answer is read by the GraphQL
/// over HTTP rules: a GraphQL response whatever the status, plain JSON only
/// with a 2xx status, at most [maxResponseBytes] bytes and
/// [maxResponseDepth] levels of nesting. The payload's context holds an
/// `HttpResponseInfo` with the status and headers. Cancelling the result
/// stream aborts the request. A subscription is refused: route it to a
/// streaming link with a `SplitLink`.
///
/// {@category http}
final class HttpLink extends Link {
  /// Creates a link that sends to [uri] through [transport], adding
  /// [headers] to every request and giving up after [timeout].
  HttpLink({
    required Uri uri,
    required HttpTransport transport,
    Map<String, String> headers = const {},
    Duration? timeout,
    int maxResponseBytes = defaultMaxResponseBytes,
    int maxResponseDepth = JsonReader.defaultMaxDepth,
  }) : _encoder = HttpRequestEncoder(uri: uri, headers: headers),
       _exchange = HttpExchange(
         transport: transport,
         reader: ResponseReader(
           maxBytes: maxResponseBytes,
           maxDepth: maxResponseDepth,
         ),
         timeout: timeout,
       ) {
    RangeError.checkNotNegative(maxResponseBytes, 'maxResponseBytes');
    RangeError.checkValueInInterval(
      maxResponseDepth,
      1,
      JsonReader.maxSupportedDepth,
      'maxResponseDepth',
    );
  }

  /// The default of `maxResponseBytes`: 16 MiB.
  static const int defaultMaxResponseBytes = 16 * 1024 * 1024;

  final HttpRequestEncoder _encoder;
  final HttpExchange _exchange;

  @override
  Stream<LinkResult> request(LinkRequest request, NextLink forward) {
    if (request.type == .subscription) {
      return Stream.value(
        LinkFailure(
          UnsupportedOperation(
            .operationNotSupportedByLink,
            'HttpLink cannot carry the subscription '
            '${request.document.name}; send subscriptions over WebSocketLink '
            'or SseLink with a SplitLink.',
          ),
        ),
      );
    }
    return _exchange.run(
      (abortTrigger) => _encoder.encode(request, abortTrigger),
    );
  }
}
```

```dart
/// Writes a [LinkRequest] as the HTTP request GraphQL over HTTP describes
/// (spec section 9).
@internal
final class HttpRequestEncoder({
  /// The GraphQL endpoint.
  required final Uri uri,
  required Map<String, String> headers,
}) {
  /// Creates an encoder; [headers] is copied with its names in lower case.
  this;

  /// The `accept` header: the GraphQL response type, then plain JSON for
  /// servers that predate it.
  static const String accept =
      'application/graphql-response+json, application/json;q=0.9';

  /// The headers the link adds to every request, names in lower case.
  final Map<String, String> headers = Map.unmodifiable({
    for (final MapEntry(:key, :value) in headers.entries)
      key.toLowerCase(): value,
  });

  /// [request] as a `POST` with a JSON body, aborted by [abortTrigger].
  TransportRequest encode(LinkRequest request, Future<void> abortTrigger) {
    final body = utf8.encode(jsonEncode(request.body.toJson().toJson()));
    return TransportRequest(
      method: 'POST',
      uri: uri,
      headers: headersFor(request, const {'content-type': 'application/json'}),
      body: Stream.value(body),
      contentLength: body.length,
      abortTrigger: abortTrigger,
    );
  }

  /// The headers of [request], lowest priority first: `accept`, the
  /// [protocol] headers, the link's [headers], then every `RequestHeaders`
  /// entry of the request's context.
  Map<String, String> headersFor(
    LinkRequest request,
    Map<String, String> protocol,
  ) => {
    'accept': accept,
    ...protocol,
    ...headers,
    for (final entry in request.context.entries.whereType<RequestHeaders>())
      ...entry.values,
  };
}
```

### Task 5: feat(typed_graphql_client): send files as multipart requests

**Why.** Spec section 9, "Uploads" (the multipart request spec). A request with `UploadFiles` is streamed as `multipart/form-data` by the internal `MultipartEncoder`: `operations` with each marker replaced by null, `map` with every path of each file, one part per file with its escaped filename and content type, a boundary of 32 letters and digits from `random`, an exact `content-length`, and the preflight header. The variable walk is breadth first with a queue. A marker without a file, or a file no variable uses, is an `ArgumentError`; a GET query with files POSTs.

```dart
import 'dart:collection';
import 'dart:convert';
import 'dart:math';

import 'package:meta/meta.dart';
import 'package:typed_graphql/typed_graphql.dart';

import '../upload/upload_file.dart';

/// Writes a request with files as the `multipart/form-data` body of the
/// GraphQL multipart request specification (spec section 9, R8.4): an
/// `operations` part with each file's marker replaced by null, a `map`
/// part from part names to variable paths, then one part per file.
@internal
final class MultipartEncoder(
  /// Draws the boundary.
  final Random random,
) {
  /// Creates an encoder.
  this;

  static const String _boundaryCharacters =
      'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789';

  static const List<int> _lineEnd = [13, 10];

  /// The body of [request] with [files]: its content type, length and
  /// bytes. A marker [files] does not list, or a listed file no variable
  /// holds, is an [ArgumentError].
  ({String contentType, int length, Stream<List<int>> body}) encode(
    GraphQLRequest request,
    UploadFiles files,
  ) {
    final operations = request.toJson().toJson();
    final paths = _MarkerWalk(files).run(operations);
    final boundary = String.fromCharCodes([
      for (var i = 0; i < 32; i++)
        _boundaryCharacters.codeUnitAt(
          random.nextInt(_boundaryCharacters.length),
        ),
    ]);
    final fields = utf8.encode(
      '${_fieldPart(boundary, 'operations', jsonEncode(operations))}'
      '${_fieldPart(boundary, 'map', jsonEncode(_map(files, paths)))}',
    );
    final heads = [
      for (final (index, file) in files.files.indexed)
        utf8.encode(_fileHead(boundary, index, file)),
    ];
    final closing = utf8.encode('--$boundary--\r\n');
    var length = fields.length + closing.length;
    for (final (index, file) in files.files.indexed) {
      length += heads[index].length + file.length + _lineEnd.length;
    }
    return (
      contentType: 'multipart/form-data; boundary=$boundary',
      length: length,
      body: _body(fields, heads, files.files, closing),
    );
  }

  Map<String, List<String>> _map(
    UploadFiles files,
    Map<UploadFile, List<String>> paths,
  ) => {
    for (final (index, file) in files.files.indexed)
      '$index': paths[file] ?? const [],
  };

  String _fieldPart(String boundary, String name, String json) =>
      '--$boundary\r\n'
      'Content-Disposition: form-data; name="$name"\r\n'
      'Content-Type: application/json\r\n'
      '\r\n'
      '$json\r\n';

  String _fileHead(String boundary, int index, UploadFile file) =>
      '--$boundary\r\n'
      'Content-Disposition: form-data; name="$index"; '
      'filename="${_escaped(file.filename)}"\r\n'
      'Content-Type: ${file.contentType}\r\n'
      '\r\n';

  /// [filename] as the HTML form encoding writes it in a header.
  String _escaped(String filename) => filename
      .replaceAll('"', '%22')
      .replaceAll('\r', '%0D')
      .replaceAll('\n', '%0A');

  Stream<List<int>> _body(
    List<int> fields,
    List<List<int>> heads,
    List<UploadFile> files,
    List<int> closing,
  ) async* {
    yield fields;
    for (final (index, file) in files.indexed) {
      yield heads[index];
      yield* file.open();
      yield _lineEnd;
    }
    yield closing;
  }
}

/// (no recursion), that replaces each file marker by null and records
/// where it was.
final class _MarkerWalk {
  _MarkerWalk(this.files);

  final UploadFiles files;
  final Map<UploadFile, List<String>> _paths = {};
  final ListQueue<(Object?, String)> _pending = ListQueue();

  /// The paths of each file in [operations], which it changes in place.
  Map<UploadFile, List<String>> run(Map<String, Object?> operations) {
    _pending.add((operations['variables'], 'variables'));
    while (_pending.isNotEmpty) {
      final (value, path) = _pending.removeFirst();
      switch (value) {
        case Map<String, Object?>():
          for (final key in value.keys.toList()) {
            value[key] = _visit(value[key], '$path.$key');
          }
        case List<Object?>():
          for (var i = 0; i < value.length; i++) {
            value[i] = _visit(value[i], '$path.$i');
          }
      }
    }
    for (final file in files.files) {
      if (!_paths.containsKey(file)) {
        throw ArgumentError.value(
          file,
          'files',
          'No variable holds this file: list only the files the variables use',
        );
      }
    }
    return _paths;
  }

  Object? _visit(Object? value, String path) {
    if (value is String && value.startsWith(UploadFile.markerPrefix)) {
      final file = files.withMarker(value);
      if (file == null) {
        throw ArgumentError.value(
          value,
          path,
          'The variables hold a file the context does not list: add it to '
          'the UploadFiles entry',
        );
      }
      (_paths[file] ??= []).add(path);
      return null;
    }
    _pending.add((value, path));
    return value;
  }
}
```

```dart
import 'dart:convert';

import 'package:test/test.dart';
import 'package:typed_graphql/typed_graphql.dart';
import 'package:typed_graphql_client/typed_graphql_client.dart';

/// Answers a server could send by mistake or on purpose (spec section 14):
/// each one ends in a typed response, never a thrown exception.
void main() {
  late FakeTransport transport;

  setUp(() => transport = FakeTransport());

  GraphQLClient client({int maxResponseBytes = 1 << 20}) => GraphQLClient(
    link: HttpLink(
      uri: Uri.parse('https://example.com/graphql'),
      transport: transport,
      maxResponseBytes: maxResponseBytes,
    ),
  );

  Future<GraphQLResponse<String>> query({int maxResponseBytes = 1 << 20}) =>
      client(maxResponseBytes: maxResponseBytes).query(const HelloQuery());

  void answerBytes(
    List<int> bytes, {
    String contentType = 'application/graphql-response+json',
  }) => transport.answerWith(
    (request) async => TransportResponse(
      statusCode: 200,
      headers: {'content-type': contentType},
      body: Stream.value(bytes),
    ),
  );

  Future<ClientFailure> failureOf(Future<GraphQLResponse<String>> response) =>
      response.then(
        (response) => switch (response) {
          GraphQLTransportFailure(:final failure) => failure,
          _ => throw StateError('Expected a failure, got $response.'),
        },
      );

  Future<DiagnosticCode> codeOf(Future<GraphQLResponse<String>> response) =>
      failureOf(response).then((failure) => failure.code);

  group('size', () {
    test('a body past the limit is GQL463', () async {
      transport.answer('{"data":{"hello":"${'x' * 2000}"}}');
      expect(
        await codeOf(query(maxResponseBytes: 1000)),
        DiagnosticCode.responseTooLarge,
      );
    });

    test('an endless body is GQL463 and is cancelled', () async {
      var isCancelled = false;
      Stream<List<int>> endless() async* {
        try {
          while (true) {
            yield List.filled(64 * 1024, 32);
          }
        } finally {
          isCancelled = true;
        }
      }

      transport.answerWith(
        (request) async => TransportResponse(
          statusCode: 200,
          headers: {'content-type': 'application/graphql-response+json'},
          body: endless(),
        ),
      );
      expect(await codeOf(query()), DiagnosticCode.responseTooLarge);
      expect(isCancelled, isTrue);
    });
  });

  group('text', () {
    for (final (name, body) in [
      ('an empty body', ''),
      ('text that is not JSON', 'Internal error'),
      ('an unfinished object', '{"data":'),
      ('100000 open braces', '{' * 100000),
      ('100000 open brackets', '[' * 100000),
    ]) {
      test('$name is GQL464', () async {
        transport.answer(body);
        expect(await codeOf(query()), DiagnosticCode.malformedResponse);
      });
    }

    test('bytes that are not UTF-8 are GQL464', () async {
      answerBytes([0x7b, 0xff, 0xfe, 0x7d]);
      expect(await codeOf(query()), DiagnosticCode.malformedResponse);
    });

    // Dart's UTF-8 decoder drops a leading byte order mark, which RFC 8259
    // section 8.1 lets a JSON parser ignore.
    test('a leading byte order mark is ignored', () async {
      answerBytes([0xef, 0xbb, 0xbf, ...utf8.encode('{"data":{"hello":"x"}}')]);
      expect(await query(), isA<GraphQLData<String>>());
    });
  });

  group('shape', () {
    for (final (name, body) in [
      ('a JSON array', '[]'),
      ('a JSON number', '1'),
      ('a JSON string', '"data"'),
      ('an object without data or errors', '{}'),
      ('data that is not an object', '{"data":[]}'),
      ('errors that are not a list', '{"data":{},"errors":{}}'),
      ('an error without a message', '{"data":{},"errors":[{}]}'),
      (
        'a message that is not a string',
        '{"data":{},"errors":[{"message":1}]}',
      ),
      (
        'a path with a boolean',
        '{"data":{},"errors":[{"message":"m","path":[true]}]}',
      ),
      (
        'a location that is not an object',
        '{"data":{},"errors":[{"message":"m","locations":[1]}]}',
      ),
      ('extensions that are not an object', '{"data":{},"extensions":[]}'),
    ]) {
      test('$name is GQL464', () async {
        transport.answer(body);
        expect(await codeOf(query()), DiagnosticCode.malformedResponse);
      });
    }

    test('a malformed error names the path of the bad value', () async {
      transport.answer('{"data":{},"errors":[{"message":1}]}');
      final failure = await failureOf(query());
      expect(failure, isA<ResponseFormatFailure>());
      expect((failure as ResponseFormatFailure).path, const [
        PathKey('errors'),
        PathIndex(0),
        PathKey('message'),
      ]);
    });

    test('null data without errors is GQL464', () async {
      transport.answer('{"data":null}');
      expect(await codeOf(query()), DiagnosticCode.malformedResponse);
    });

    test('an empty list of errors without data is GQL464', () async {
      transport.answer('{"errors":[]}');
      expect(await codeOf(query()), DiagnosticCode.malformedResponse);
    });

    test('data of the wrong shape is a data format failure', () async {
      transport.answer('{"data":{"hello":7}}');
      final failure = await failureOf(query());
      expect(failure, isA<DataFormatFailure>());
      expect(failure.code, DiagnosticCode.dataShapeMismatch);
    });

    test('data without the selected field is a data format failure', () async {
      transport.answer('{"data":{}}');
      expect(await failureOf(query()), isA<DataFormatFailure>());
    });
  });

  group('content type and status', () {
    for (final (name, type) in [
      ('a missing content type', ''),
      ('an HTML page', 'text/html'),
      ('a malformed content type', ';;=;'),
      ('a charset other than UTF-8', 'application/json; charset=latin1'),
    ]) {
      test('$name with 200 is GQL462', () async {
        transport.answer('{"data":{"hello":"x"}}', contentType: type);
        expect(await codeOf(query()), DiagnosticCode.unsupportedResponseType);
      });
    }

    test('a 500 with JSON is an HTTP status failure', () async {
      transport.answer(
        '{"data":{"hello":"x"}}',
        status: 500,
        contentType: 'application/json',
      );
      final failure = await failureOf(query());
      expect(failure, isA<HttpStatusFailure>());
      expect((failure as HttpStatusFailure).statusCode, 500);
    });

    test('a 401 with a GraphQL response is read as the response', () async {
      transport.answer(
        '{"errors":[{"message":"Unauthorized"}]}',
        status: 401,
      );
      final response = await query();
      expect(response, isA<GraphQLErrors<String>>());
      expect(
        (response as GraphQLErrors<String>).errors.single.message,
        'Unauthorized',
      );
    });
  });

  test('a body stream that throws an exception is a network failure', () async {
    transport.answerWith(
      (request) async => TransportResponse(
        statusCode: 200,
        headers: {'content-type': 'application/graphql-response+json'},
        body: Stream.error(const FormatException('connection reset')),
      ),
    );
    expect(await codeOf(query()), DiagnosticCode.networkFailure);
  });

  test(
    'a body that ends after the first chunk of an object is GQL464',
    () async {
      final body = StreamController<List<int>>();
      transport.answerWith(
        (request) async => TransportResponse(
          statusCode: 200,
          headers: {'content-type': 'application/graphql-response+json'},
          body: body.stream,
        ),
      );
      final response = query();
      body.add(utf8.encode('{"data":{"hel'));
      await body.close();
      expect(await codeOf(response), DiagnosticCode.malformedResponse);
    },
  );
}
```

## Review Focus

- Media types and statuses follow GraphQL over HTTP exactly (section 9 table): `application/graphql-response+json` is read for any status, `application/json` only for 2xx.
- The byte limit is counted while streaming and the request is aborted past it; an endless body ends in bounded memory.
- Header priority: protocol, link `headers`, then each `RequestHeaders` entry; GET and multipart add `graphql-require-preflight: true`; a mutation never goes as GET.
- Cancellation aborts through `abortTrigger` and delivers nothing; the timeout covers sending and reading the body.
- Multipart: markers replaced by null in `operations`, `map` lists every path, filenames escaped, `content-length` exact, the variable walk is iterative; a missing or unused file is an `ArgumentError`.
- `PackageHttpTransport` is the only `package:http` user; the import rule allows only the `http.dart` barrel.
